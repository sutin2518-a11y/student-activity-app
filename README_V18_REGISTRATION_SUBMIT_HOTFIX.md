# Group Sports – v18 Registration Submit Hotfix

ฐาน: โครงการ v18 Print Hotfix (ธีมแดง–ขาว, ระบบพิมพ์ PDF)

## เปลี่ยนแปลง
- ตรวจข้อมูลนักกีฬาในทุกแถวก่อนส่ง โดยแจ้งเลขคนที่กรอกคำนำหน้าหรือชื่อ–สกุลไม่ครบ
- สำหรับ RoV ตรวจชื่อในเกม (IGN), จำนวนตัวจริง, หัวหน้าทีม, ตัวสำรอง
- ตรวจครูผู้ควบคุมรายคน รวมเบอร์โทรศัพท์ 9–15 หลัก
- แก้กรณีมีเฉพาะคำนำหน้าชื่อแต่ไม่มีชื่อ–สกุล (เดิมอาจผ่านการตรวจ)
- ไม่ให้ HTML required ของเบราว์เซอร์เงียบ ๆ ขวางคำสั่งส่ง: เปลี่ยนมาใช้การตรวจใน submit handler พร้อมข้อความไทย
- แจ้งข้อผิดพลาดจาก Supabase (เช่นสิทธิ์, RPC ใน schema cache หรือรายการซ้ำ) อยู่ข้างปุ่มส่งข้อมูล
- ไม่เปลี่ยนกติกากีฬา, ข้อมูลที่ลงทะเบียนไว้, ฐานข้อมูล, การพิมพ์ PDF หรือระบบนำเข้า Excel

## ติดตั้ง
1. คัดลอก `src/components/group-sports/GroupSportsDashboard.tsx` จาก ZIP ทับไฟล์เดิม
2. Commit, Push และทดสอบบน Vercel Preview ก่อนนำขึ้น Production
3. โหลดหน้าใหม่ เลือก RoV ทดสอบนำเข้า Excel และกดส่ง
4. ถ้าพบกล่องแดงข้างปุ่มส่ง ให้ทำตามข้อความ หรือส่งข้อความ (ไม่ต้องส่งข้อมูลส่วนตัวของนักเรียน) เพื่อตรวจต่อ

ไม่ต้องรัน SQL เพิ่มสำหรับแพตช์นี้ หากปรากฏข้อผิดพลาด RPC/schema ต้องตรวจว่าติดตั้ง Migration 0015 ที่ระบบเดิมต้องใช้แล้ว

## การตรวจสอบ
ผ่านการ parse TS/TSX ครบทั้งโครงการด้วย TypeScript compiler API; ยังไม่ได้รัน Next.js Production Build หรือ Supabase จริงในสภาพแวดล้อมนี้
