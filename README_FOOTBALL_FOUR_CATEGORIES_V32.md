# v32 — ฟุตบอล 4 ประเภท (ภูลังกาเกมส์ 2569)

## สิ่งที่ทำในเวอร์ชันนี้

- เพิ่มหน้า `/group-sports/football` แยกจาก RoV โดยเข้าจาก **ผลการแข่งขัน → ฟุตบอล 4 ประเภท** หรือ **ลงทะเบียนนักกีฬา → ฟุตบอล 4 ประเภท**
- ชื่อรายการตามภาพที่คณะกรรมการยืนยัน:
  1. ฟุตบอล รุ่นอายุไม่เกิน 13 ปี ชาย (`GS3-FB-13M`)
  2. ฟุตบอล รุ่นอายุไม่เกิน 15 ปี ชาย (`GS3-FB-15M`)
  3. ฟุตบอล รุ่นไม่จำกัดอายุ ชาย (`GS3-FB-UM`)
  4. ฟุตบอล รุ่นไม่จำกัดอายุ หญิง (`GS3-FB-UF`)
- แบ่งสายตาม PDF และนำโปรแกรมรวม **51 คู่** ลงตารางฐานข้อมูลจริง (9 + 17 + 16 + 9 คู่) เป็นสถานะ **ฉบับร่าง** ตั้งแต่แรกเพื่อให้ Admin ตรวจสอบก่อนเผยแพร่ ไม่ใช้ตารางเวลาที่หน้าเว็บสร้างขึ้นเอง
- เมนูโปรแกรม/ผล แก้วัน เวลา สนาม ทีม คู่แข่งขัน และผลประตู/จุดโทษได้โดย Admin หลัก; มีการบันทึกประวัติแก้ไข
- ตารางคะแนนคำนวณจากผลกลุ่มที่บันทึกแล้ว ชนะ 3 แพ้ 0; เสมอในเวลาปกติให้บันทึกผลยิงจุดโทษ; เมื่อต้องตัดสินผลพบกันหรือจับสลากต้องให้คณะกรรมการตัดสิน
- การเข้ารอบ U13 ชาย/หญิง และ U15 ชายแสดงข้อเสนอแนะผู้ผ่านเข้ารอบหลังจบผลกลุ่ม; อันดับที่ยังเสมอกันไม่ถูกตัดสินแทนกรรมการ; ฟุตบอลชายไม่จำกัดอายุต้องจับสลากเพิ่ม 2 ทีมอันดับ 3 แล้วกำหนดทีมรอบแปดทีมด้วยตนเอง
- ลงทะเบียนนักกีฬาภายใต้บัญชีโรงเรียน 1 ใบสมัครต่อโรงเรียน/ประเภท เก็บคำนำหน้า ชื่อ-สกุล รหัสนักเรียน (ถ้ามี) วันเกิด หมายเลขเสื้อ บทบาท ผู้ควบคุมทีมหลายคนและเบอร์โทรศัพท์; ตรวจแค่ความครบของฟิลด์ ไม่ตรวจเงื่อนไขคุณสมบัติตามระเบียบ
- ดาวน์โหลด/นำเข้า Excel แบบเฉพาะรุ่นพร้อมตรวจรายชื่อก่อนบันทึก
- แนบรูปจากระบบ private Storage เดิมหลังบันทึก โดยไม่ลงทะเบียนใหม่ และพิมพ์ใบสมัคร / ใบส่งรายชื่อ / แผงรูปผ่านเมนูพิมพ์เป็น PDF (`/group-sports/football/print?entry=...`)
- แสดง PDF ต้นฉบับ 3 ฉบับให้ดาวน์โหลด โดยรุ่น U13 ชายและหญิงไม่จำกัดอายุใช้ไฟล์เดียวกัน

## ติดตั้งจาก v31

1. **สำรอง Supabase ก่อนทำเสมอ** โดยเฉพาะ `sports_events`, `sports_entries`, `sports_athletes`, `sports_schedule_sessions` และข้อมูลการแข่งขันเดิม
2. ตรวจว่ารัน Migration 0003–0025 ตามลำดับสำเร็จ รวมถึง SQL hotfix ของ v31 (0025) แล้ว
3. เปิด `supabase/migrations/202611230026_sports_football_four_categories.sql` ใน **Supabase SQL Editor** แล้วรันทั้งไฟล์ 1 ครั้ง
4. ผล SQL ที่ถูกต้องคือ `Success. No rows returned` โดย **ยังไม่เผยแพร่โปรแกรมหรือเปิดรับสมัครทันที**
5. แตก Patch v32 คัดลอกตามโครงสร้างไฟล์ทับ project v31 (หรือเลือกโครงการฉบับเต็ม v32)
6. Commit → Push ผ่าน GitHub Desktop และตรวจ Vercel Preview ให้ Build ผ่าน
7. เข้าหน้า `/group-sports/football` ด้วยบัญชี Admin หลัก ตรวจว่าแต่ละรุ่นมี 9/17/16/9 คู่และกลุ่มถูกต้อง
8. ตรวจและแก้ชื่อสนาม วันที่ เวลา ชื่อทีมของทุกคู่ให้ตรงคำสั่งคณะกรรมการ
9. กด **เปิดรับสมัคร / เปิดรายการ** เพื่อให้โรงเรียนมองเห็นรุ่นนั้นและลงทะเบียนได้ (แยกรุ่น)
10. กด **เผยแพร่โปรแกรม** เมื่อยืนยันรายการแล้ว (แยกรุ่น)
11. ทดสอบโดยเข้าใช้บัญชีโรงเรียนหนึ่งแห่ง: ลงทะเบียน Excel / กรอกมือ → แนบรูป → พิมพ์ PDF; ทดสอบโหมด Incognito ว่าดูได้เฉพาะโปรแกรมที่เผยแพร่

## ข้อควรตรวจจากต้นฉบับ

- **U13 ชาย + หญิงไม่จำกัดอายุ**: PDF เดียว, 18 คู่ รวม 9 คู่ต่อรุ่น, แข่ง 30 พ.ย.–4 ธ.ค. ณ โรงเรียนภูซางวิทยาคม
- **U15 ชาย**: 17 คู่, แข่ง 2–7 ธ.ค. ณ โรงเรียนฝายกวางวิทยาคม, แบ่ง 4 สาย A–D
- **ไม่จำกัดอายุ ชาย**: 16 คู่, หัวโปรแกรมวันที่ 30 พ.ย.–7 ธ.ค. แต่หน้าระเบียบระบุถึง 8 ธ.ค. ต้องตรวจวันจริงก่อนเผยแพร่ และคู่ 7–9 ของรอบกลุ่มมีชื่อสายบนตารางไม่ตรงกับสายของโรงเรียน แสดงสายจากทีมจริง A/B/C ในระบบและแจ้งหมายเหตุไว้
- รูปแบบการแข่งขันและการจัดอันดับยึด PDF ที่แนบ ไม่สร้างระบบตรวจสอบคุณสมบัติผู้เล่นอัตโนมัติ เช่น อยู่ในโรงเรียนกี่เดือน ประวัติลีก จำนวนครั้งเปลี่ยนตัว หรือเวลาครึ่งละกี่นาที
- **ฟุตบอลชายไม่จำกัดอายุ**: ระเบียบระบุรายชื่อ 15–20 คน แต่แบบใบส่งรายชื่อหน้า 4 มีช่อง 22 แถว ระบบจึงรับได้สูงสุด 20 คนและคงแผ่นพิมพ์ 22 ช่องตามภาพ; แผงรูปที่เพิ่มสำหรับรุ่นนี้เป็นเอกสารประกอบ ไม่ใช่แบบฟอร์มใน PDF เดิม

## ข้อควรทราบเกี่ยวกับสิทธิ์และการทดสอบ

- SQL นี้ **ไม่ลบ ไม่รีเซต และไม่แก้ผล RoV**
- การติดตั้งไม่ได้แต่งตั้งกรรมการฟุตบอลโดยอัตโนมัติ บันทึกผลและเผยแพร่สำหรับบัญชี Admin การแข่งขันหลักเท่านั้น ส่วนโรงเรียนที่มีสิทธิ์ `school_manager` จัดการใบสมัครของโรงเรียนตนเองได้
- ชื่อทีมในรอบน็อกเอาต์ที่อ้างอิงผลกลุ่มเป็นข้อเสนอแนะจากผลจริง ต้องให้กรรมการยืนยันก่อนบันทึกผลและเผยแพร่
- การดาวน์โหลด PDF ผ่านปุ่ม **พิมพ์ / บันทึกเป็น PDF** ของเบราว์เซอร์ ต้องเปิดด้วยบัญชีที่มีสิทธิ์ดูรายชื่อนักกีฬา
- ข้อมูลนักกีฬา วันเกิด เบอร์โทรครู และภาพถ่ายถูกจำกัดสิทธิ์ใน RPC และ private Storage ไม่แสดงให้ผู้ชมทั่วไป
- หาก Admin เปิดรับสมัครเพียงบางประเภท ผู้ชมทั่วไปจะเห็นเฉพาะประเภทที่เปิดแล้ว
