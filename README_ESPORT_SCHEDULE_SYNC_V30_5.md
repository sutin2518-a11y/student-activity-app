# v30.5 — RoV: ตารางโปรแกรมมีวันเวลา แต่เผยแพร่ไม่ได้

## สาเหตุที่ตรวจพบในโค้ด

หน้า **ตารางโปรแกรม** สร้างวันเวลาเพื่อแสดงผลจาก `makePlan()` ใน `src/components/group-sports/EsportsSessionSchedule.tsx` โดยกำหนดสล็อตการแข่งขันในโค้ด ส่วนปุ่ม **เผยแพร่โปรแกรม** อ่าน `sports_esports_matches.scheduled_date` และ `sports_esports_matches.start_time` จาก Supabase จริง จึงเกิดอาการเห็นวันเวลาบนตารางครบแต่ข้อความแจ้งว่า 29 คู่ฉบับร่างยังขาดวันหรือเวลา

Migration `202611210004_esports_management.sql` สร้างคู่กลุ่มเป็น `draft` โดย **ไม่มีวันและเวลาในตาราง matches** ขณะที่สร้างกรอบเวลาระดับอีเวนต์แยกใน `sports_schedule_sessions` จึงไม่ควรนำกรอบเวลาระดับอีเวนต์มาถือว่าเป็นเวลาเฉพาะคู่โดยอัตโนมัติ

## สิ่งที่แก้

- เพิ่มกล่อง **ตรวจและบันทึกวันเวลาจากแผนเข้าสู่ฐานข้อมูล** ภายใน `/group-sports/esports` → **ตารางโปรแกรม** (Admin เท่านั้น)
- แสดงจำนวนคู่ฉบับร่างที่วันและ/หรือเวลาจริงยังว่าง แยกทีมชาย/ทีมหญิง
- แสดงรายการพรีวิวทุกคู่ที่จะเติม: ชื่อทีม, วันเวลาเดิม, วันเวลาตามแผน
- ต้องติ๊กยืนยันและกดตกลงอีกครั้งก่อนบันทึก เพราะตารางที่คำนวณขึ้นอาจยังไม่ใช่โปรแกรมที่คณะกรรมการรับรอง
- บันทึกเฉพาะช่องที่ว่างเท่านั้น ไม่เขียนทับวันที่/เวลาซึ่งกรอกแล้ว ไม่เปลี่ยนสถานะเป็น `scheduled` ไม่เปลี่ยนคะแนน ไม่แก้คู่ที่ยกเลิกหรือแข่งขันเสร็จสิ้น และไม่แตะข้อมูลรอบ Knockout
- ใช้ RLS Admin เดิมและเงื่อนไข UPDATE ที่ตรวจช่องว่างซ้ำเพื่อป้องกันการทับข้อมูลที่ถูกแก้ไขระหว่างเปิดพรีวิว
- หากมีรายการที่บันทึกไม่ได้ ระบบแสดงจำนวนที่สำเร็จ/ไม่สำเร็จและให้ตรวจ/ลองเฉพาะรายการคงค้าง ระบบอาจบันทึกสำเร็จบางส่วนหากมีปัญหาเครือข่าย
- ปรับข้อความผิดพลาดการเผยแพร่ให้อธิบายความต่างระหว่างตารางที่แสดงกับข้อมูลจริง

## วิธีอัปเดตจาก v30.4

1. สำรองโครงการก่อนแตก Patch
2. แตก `student-activity-esport-schedule-sync-v30.5-patch.zip` ทับโปรเจกต์ v30.4 โดยรักษา path เดิม
3. Commit และ Push ผ่าน GitHub Desktop; ตรวจ Vercel Preview ให้ Build สำเร็จ
4. ไม่ต้องรัน SQL ใหม่ และไม่ต้องเปลี่ยน Environment Variables

## วิธีใช้งาน

1. เข้าระบบด้วยบัญชี Admin ที่มีสิทธิ์ `sports_stage3_admin` → E-Sport → **ตารางโปรแกรม**
2. เลือก **ทีมชาย** แล้วกด **ตรวจและบันทึกวันเวลาจากแผน (… คู่)**
3. ตรวจรายการพรีวิว (โดยเฉพาะช่วงวันที่ 5–6 ธันวาคม 2569 และช่วงเวลา 09:00–16:00 ที่ระบบสร้างเป็นแผนตัวอย่าง) ว่าตรงกับกำหนดการที่คณะกรรมการรับรองจริง หากไม่ตรง อย่ากดยืนยัน ให้แก้ไขวันเวลารายคู่ด้วยฟอร์ม **โปรแกรม / ผล** แทน
4. หากตรง ให้ติ๊กยืนยัน แล้วกด **ยืนยันบันทึกวันเวลาที่ขาด (ไม่เผยแพร่)**
5. รีเฟรชและตรวจว่าจำนวนคู่ที่ขาดเป็นศูนย์ แล้วค่อยกด **เผยแพร่โปรแกรมทีมชาย** เมื่อยืนยันแล้ว
6. หากมีทีมหญิง ให้ทำแยกตามประเภท
7. ทดลองเปิดใน Incognito เพื่อตรวจผลสำหรับโรงเรียนและผู้ชมทั่วไป

**ข้อควรระวัง:** แผน `makePlan()` กำหนดวันเวลาเชิงอัลกอริทึมตามกลุ่ม/รอบในโค้ด ไม่ใช่หลักฐานว่าวันเวลานั้นได้รับอนุมัติจากคณะกรรมการแล้ว โปรดตรวจเป็นรายคู่ก่อนบันทึกและเผยแพร่ หากมีการรีเซตข้อมูลทดสอบจาก v30.3 ให้ตรวจและซิงก์ข้อมูลอีกครั้งก่อนเผยแพร่
