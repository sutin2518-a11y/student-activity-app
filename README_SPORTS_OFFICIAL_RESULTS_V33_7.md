# ระบบมอบหมายกรรมการและบันทึกผลการแข่งขัน v33.7

## สิ่งที่เปลี่ยน

แยกหน้าการทำงานจากหน้าเดียวเดิมเป็น 3 URL โดยใช้ตารางและ RPC ที่ติดตั้งอยู่แล้วใน Certificate V1 ไม่สร้างตารางผลซ้ำ และไม่เปลี่ยนข้อมูลการแข่งขันเดิม

- `/group-sports/officials` — Admin มอบหมาย/ระงับกรรมการรายรายการผ่าน `sports_cert_set_official` และดูรายการผ่าน `sports_cert_officials`
- `/group-sports/results` — กรรมการเห็นเฉพาะรายการที่ได้รับมอบหมายจาก `sports_cert_context` และส่งอันดับ 1–3/อันดับ 3 ร่วม (เฉพาะกีฬาทั่วไป) ผ่าน `sports_cert_submit`
- `/group-sports/results/review` — Admin ตรวจผล อนุมัติ ส่งกลับแก้ไข หรือเผยแพร่ผ่าน `sports_cert_review`
- `/group-sports/certificates` — โรงเรียนยังคงพิมพ์เกียรติบัตรของโรงเรียนตนเองเหมือนเดิม
- `/group-sports/certificates/manage` — คงหน้าเดิมสำหรับจัดการเกียรติบัตร การยกเลิก/ออกฉบับใหม่ และตั้งค่าไว้เพื่อ backward compatibility

## สิทธิ์

- กรรมการต้องลงชื่อด้วย Google account ที่ยืนยันอีเมลแล้ว และต้องถูกมอบหมายตรงกับ event นั้น
- กรรมการไม่มีสิทธิ์อนุมัติ/เผยแพร่ผลหรือมอบหมายกรรมการคนอื่น
- เฉพาะ Admin ที่ `sports_cert_context` ระบุ role เป็น `admin` เท่านั้นจึงจะเห็น/ใช้หน้ามอบหมายและหน้าอนุมัติได้
- Backend RPC เดิมยังตรวจสิทธิ์ทุกครั้ง ไม่ได้พึ่งการซ่อนเมนูฝั่ง UI อย่างเดียว

## ขอบเขตที่ไม่เปลี่ยน

- ไม่แก้ schema, ไม่เพิ่ม SQL migration และไม่ต้องรัน SQL ใหม่ เพราะใช้ RPC จาก `202611230027_sports_certificates_v1.sql` ที่มีอยู่แล้ว
- ไม่เปลี่ยนระบบฟุตบอล, RoV/E-Sport, โปรแกรมแข่งขัน, ตารางคะแนนกลาง, ระบบลงทะเบียน, ระบบรีเซต v33.6 หรือการออก/ยกเลิกเกียรติบัตร
- หน้าบันทึกผลนี้เป็นการส่งอันดับผู้ชนะเพื่ออนุมัติและออกเกียรติบัตร ไม่ใช่การบันทึกสกอร์ของแมตช์ฟุตบอลหรือ RoV ซึ่งยังใช้หน้าระบบเฉพาะกีฬาเดิม

## ติดตั้ง

1. สำรอง/Commit โปรเจกต์ล่าสุดก่อน
2. แตก ZIP เฉพาะไฟล์ที่แก้ไข แล้ววางทับตาม path ใน ZIP
3. ไม่ต้องรัน SQL
4. รัน `npm run build`
5. Commit + Push แล้วทดสอบด้วยบัญชี Admin และบัญชีกรรมการที่ได้รับมอบหมาย

## ทดสอบที่ต้องทำ

1. Admin เปิด `/group-sports/officials` เลือกรายการ เพิ่มอีเมลกรรมการ
2. กรรมการเข้าสู่ระบบ Google ที่ตรงกับอีเมลที่มอบหมาย แล้วเปิด `/group-sports/results`
3. ตรวจว่ากรรมการเห็นเฉพาะรายการที่ได้รับมอบหมาย และส่งผลได้
4. Admin เปิด `/group-sports/results/review` ตรวจผล อนุมัติ หรือส่งกลับแก้ไข
5. เมื่ออนุมัติแล้วจึงเผยแพร่ผลและสร้างเกียรติบัตรรางวัล
6. ทดสอบบัญชีโรงเรียนว่าไม่เห็นเมนูกรรมการและยังพิมพ์ได้เฉพาะเอกสารของโรงเรียนตนเอง
