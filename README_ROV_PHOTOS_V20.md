# v20 — รูปถ่ายนักกีฬา RoV ในผังใบสมัคร PDF

ต่อยอดจาก **v19** (แบบพิมพ์ RoV A4 สองหน้า) เพิ่มภาพถ่ายนักกีฬาแบบ Private ใน Supabase Storage เท่านั้น **ไม่เปลี่ยน RPC ลงทะเบียนหรือฐานข้อมูลใบสมัครเดิม**

## ติดตั้ง

1. สำรองโปรเจกต์ v19 และรัน `supabase/migrations/202611220016_rov_athlete_private_photos.sql` ใน Supabase SQL Editor **หลัง Migration 0015**
2. คัดลอก Source Code ของ Patch v20 ทับโครงการเดิมตาม path ใน ZIP
3. Commit → Push → ตรวจ Vercel Preview → ทดสอบก่อนขึ้น Production
4. บัคเก็ต `sports-athlete-photos` จะถูกสร้างเป็น **Private** โดย SQL; ไม่ต้องสร้าง Public bucket หรือเพิ่ม Environment Variable

## วิธีใช้งาน

- เลือก **RoV** ในเมนูลงทะเบียน และกรอกรายชื่อนักกีฬา หรืออัปโหลดเทมเพลต Excel ตามปกติ
- ในแต่ละช่องนักกีฬา กด **เลือกรูป JPG / PNG / WebP** ขนาดไม่เกิน 5 MB; แนะนำรูปหน้าตรงพื้นเรียบ แนวตั้ง
- กด **ส่งข้อมูลลงทะเบียน** ระบบจะบันทึกใบสมัครก่อน และอัปโหลดรูปที่เลือกตามลำดับนักกีฬา
- ไปที่ **ลงทะเบียน → ดูรายชื่อ** ของใบสมัคร RoV ที่บันทึกแล้ว จะมีส่วน **รูปถ่ายนักกีฬา RoV** แสดงรูปแต่ละคน พร้อมปุ่ม **แนบรูป / เปลี่ยนรูป** (รองรับกรณีลืมแนบหรืออัปโหลดบางรูปไม่สำเร็จ)
- กด **พิมพ์ใบสมัคร PDF** หน้าแรกยังเป็นตารางรายชื่อ 10 แถว หน้า 2 ใช้รูปจริงที่แนบในกรอบ 7 ช่อง (3–3–1) พร้อมช่องลงนาม; คนที่ไม่มีรูปจะเว้นกรอบไว้
- ข้อมูลรหัสนักเรียน ชื่อในเกม และตำแหน่งเล่นยังเก็บในระบบตามเดิม ไม่พิมพ์บนผังรูป

## วิธีป้องกันรูปสลับคน / ความเป็นส่วนตัว

- ตำแหน่งไฟล์ประกอบด้วย UUID ใบสมัคร ลำดับในทะเบียน และแฮช SHA-256 ของชื่อ/รหัสนักเรียน **ไม่มีชื่อนักเรียนใน path**
- หากแก้ลำดับหรือชื่อหลังจากแนบรูปแล้ว ภาพเดิมจะ **ไม่ถูกนำไปแสดงเป็นของคนใหม่** ต้องแนบรูปให้คนที่แก้ใหม่
- ภาพย่อถูกแปลงเป็น JPEG สูงสุด 900×1200 พิกเซลก่อนอัปโหลด (ไฟล์หลังแปลงต้องไม่เกิน 3 MB)
- Supabase Storage เป็น Private พร้อม RLS ตรวจสิทธิ์ `school_manager` ของโรงเรียน/การแข่งขัน หรือ `competition_admin`/`super_admin`
- การพิมพ์โหลดรูปผ่านสิทธิ์ผู้ลงชื่อเข้าใช้เป็น Blob URL ในเบราว์เซอร์ ไม่ใช้ Public URL; Blob URL จะถูกคืนหน่วยความจำหลังออกจากหน้า
- **ควรขอความยินยอม/ดำเนินการตามนโยบายโรงเรียนสำหรับภาพนักเรียน** และอย่าแจกเอกสาร PDF ที่มีรูปถ่ายเป็นสาธารณะ

## ข้อจำกัดและการทดสอบ

- ภาพถ่ายแนบจากไฟล์แยกรายคน (ยังไม่รองรับ ZIP หลายรูปในการอัปโหลดครั้งเดียว)
- หากอัปโหลดรูปบางคนล้มเหลว **ใบสมัครที่ส่งสำเร็จยังคงอยู่** ให้เปิดหน้า ดูรายชื่อ แล้วกดแนบใหม่ ไม่ต้องส่งใบสมัครซ้ำ
- ทดสอบการตรวจไวยากรณ์ TypeScript/TSX ผ่าน และการเรนเดอร์แม่แบบภาพตัวอย่าง 7 รูปใน PDF **2 หน้า A4** ผ่าน
- **ยังไม่ได้ทดสอบกับ Supabase จริงหรือ Production Build** กรุณาเปิด Vercel Preview และทดสอบบัญชีโรงเรียน/ผู้ดูแลก่อนใช้ข้อมูลจริง
