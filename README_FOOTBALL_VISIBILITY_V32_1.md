# v32.1 — แก้ความเข้าใจเรื่องโปรแกรมฟุตบอลไม่แสดง

**เหตุผล:** v32 นำเข้าโปรแกรม 51 คู่ในสถานะ `draft` โดยเจตนาให้ Admin ตรวจทานก่อนเผยแพร่; Supabase RLS ซ่อนรายการแข่งขัน `sports_events.status='draft'` และซ่อนคู่แข่งขัน `sports_football_matches.status='draft'` จากผู้ชมทั่วไป จึงทำให้แท็บ **โปรแกรม/ผล, แบ่งสาย, ตารางคะแนน** ดูเหมือนข้อมูลหาย โดยเฉพาะหน้า 0/9, 0/17 ทั้งที่ข้อมูลอาจมีในฐานข้อมูลอยู่แล้ว

## สิ่งที่ปรับใน v32.1

- เพิ่มปุ่ม `เปิดแสดงรุ่นนี้ (ยังไม่รับสมัคร)` สำหรับ Admin หลัก: เปลี่ยนสถานะรายการจาก `draft` เป็น `scheduled` ทำให้โรงเรียน/ผู้ชมเห็น **รายชื่อสาย** แต่ยังไม่เปิดรับสมัครและยังไม่เผยแพร่คู่แข่งขัน
- ปุ่ม `เผยแพร่โปรแกรม (N คู่)` ทำงานแยกจากการเปิดรับสมัคร และเผยแพร่ได้หลัง Admin เปิดแสดงรุ่นแล้ว รวมถึงตรวจวัน เวลา สนามครบทุกคู่
- `เปิดรับสมัครนักกีฬา` ยังคงเป็นการตัดสินใจแยกต่างหาก ไม่เปิดรับสมัครโดยอัตโนมัติ
- ถ้าผู้ใช้ไม่มีสิทธิ์เห็นข้อมูล จะแสดง `— / จำนวนตาม PDF` และคำอธิบายแทนตัวเลข 0 ที่อาจทำให้เข้าใจผิด
- **ไม่มีการเปลี่ยนแปลง SQL/RLS และไม่มีการเผยแพร่ข้อมูลอัตโนมัติ** เพื่อไม่ให้ฉบับร่างที่คณะกรรมการยังไม่ได้ตรวจปรากฏต่อสาธารณะ

## การติดตั้ง

1. ใช้โครงการ v32 เป็นฐาน (ต้องติดตั้ง SQL Migration `202611230026_sports_football_four_categories.sql` เรียบร้อย)
2. คัดลอกไฟล์ `src/components/group-sports/FootballDashboard.tsx` จาก Patch ทับของเดิม
3. Commit และ Push ผ่าน GitHub Desktop แล้วตรวจ Vercel Preview
4. **ล็อกอินบัญชี Admin หลักของการแข่งขัน** (ไม่ใช่บัญชีโรงเรียนหรือ Admin เฉพาะ RoV)
5. เปิด `/group-sports/football` > เลือกประเภทรุ่น > `โปรแกรม / ผล`
6. ตรวจโปรแกรม 9 / 17 / 16 / 9 คู่ แล้วกด **เปิดแสดงรุ่นนี้ (ยังไม่รับสมัคร)** เพื่อให้รายชื่อสายแสดงแก่ผู้ชมทั่วไป
7. กด **เผยแพร่โปรแกรม** เมื่อยืนยันวัน เวลา สนาม และคู่แข่งขันครบถ้วน; ทำซ้ำทุกประเภท
8. กด **เปิดรับสมัครนักกีฬา** เฉพาะเมื่อพร้อมเปิดฟอร์มให้โรงเรียนใช้งาน
9. ทดสอบ Incognito ว่า `โปรแกรม / ผล`, `แบ่งสาย`, `ตารางคะแนน` แสดงตรงกับที่เผยแพร่

## หากยังขึ้นว่าไม่มีข้อมูล

เปิด `diagnostics/football-v32-1-check-read-only.sql` แล้วรันใน Supabase SQL Editor ผลที่คาดก่อนเผยแพร่:

| event_code | matches_in_database |
| --- | ---: |
| GS3-FB-13M | 9 |
| GS3-FB-15M | 17 |
| GS3-FB-UM | 16 |
| GS3-FB-UF | 9 |

- **ไม่มีตาราง `sports_football_matches`:** ยังไม่ได้รัน Migration 0026 หรือรันไม่ครบ
- **ไม่พบรายการใน `sports_events`:** ตรวจว่าฐานข้อมูลที่รัน SQL เป็น Supabase Project เดียวกับ Vercel และรัน SQL สำหรับรายการการแข่งขันขั้นก่อนหน้า
- **มีรายการแต่คู่เป็น 0:** Migration 0026 seed ไม่เข้า; ห้ามสร้างคู่เดิมซ้ำโดยไม่ได้ตรวจข้อมูล
- **มีคู่ครบแต่สถานะ `draft`:** ต้องเปิดแสดงรายการและเผยแพร่ด้วยบัญชี Admin หลัก ไม่ใช่ปัญหาข้อมูลสูญหาย
- **บัญชี Admin เห็นข้อมูล แต่ผู้ชมทั่วไปไม่เห็น:** ตรวจสถานะ `event_status` และ `published_matches` ตามรายรุ่น
- **บัญชีที่คิดว่าเป็น Admin ไม่เห็นปุ่มเปิดแสดง:** ตรวจว่าบัญชีนั้นมี `sports_user_roles` = `competition_admin` สำหรับการแข่งขันนี้ หรือ `super_admin`; สิทธิ์ Admin เฉพาะ RoV ไม่ใช่ Admin ฟุตบอล

**ข้อควรทราบ:** ตารางคะแนนก่อนบันทึกผลจะเป็นศูนย์ทุกทีมตามปกติ การแบ่งสายไม่จำเป็นต้องมีผลคะแนนก่อนจึงแสดงได้

ไม่ต้องรัน SQL ใหม่เพื่อใช้ Patch นี้; SQL ที่แนบเป็นการตรวจสอบแบบอ่านอย่างเดียว ไม่แก้ไขข้อมูลใด ๆ
