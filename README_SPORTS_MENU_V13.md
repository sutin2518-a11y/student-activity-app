# ระบบกีฬากลุ่ม — เมนูรวมแบบเลื่อนลง (v13)

อัปเดตจากระบบกิจกรรมเวอร์ชัน 12 โดย **ไม่เปลี่ยนโครงสร้างฐานข้อมูลหรือ API**

## สิ่งที่เปลี่ยน

- รวม 3 เมนูเดิมเข้าเป็นปุ่ม **จัดการแข่งขัน** ในแถบหลัก:
  1. จัดการ / ดูโปรแกรม (ยังใช้ `SportsScheduleContent` เหมือนเดิม)
  2. รายการแข่งขัน (ยังใช้หน้ารายการแข่งขันเดิม)
  3. โปรแกรม / ผล (ยังใช้หน้าโปรแกรม/ผลเดิม)
- แถบเมนูหลักเหลือ 8 ปุ่ม โดยยังคงเมนู **บัญชีโรงเรียน** ให้มองเห็นได้
- คลิก `จัดการแข่งขัน` จะเลื่อนแผงเมนูย่อยลงอย่างนุ่มนวล (~360 ms)
- เลือกเมนูย่อยแล้วสลับเนื้อหาในหน้าเดิม และปิดแผงโดยอัตโนมัติ
- แสดงสถานะที่เลือกเด่นชัด: พื้นกรมท่า ไอคอน/ตัวอักษรสีขาว ขอบฟ้าและเรืองแสงอ่อน ๆ พร้อมเส้นไฮไลต์สีทอง
- ผู้ใช้ที่ตั้งค่า `prefers-reduced-motion` จะไม่ถูกบังคับให้รับภาพเคลื่อนไหว
- รองรับการกด Escape เพื่อปิดเมนูย่อย และกำหนด `aria-expanded`, `aria-controls`, `aria-hidden` สำหรับการเข้าถึง

## วิธีอัปเดต

1. สำรองหรือ Commit โครงการเดิมก่อน
2. แตกไฟล์ `student-activity-sports-menu-v13-patch.zip` ใน **โฟลเดอร์รากโปรเจกต์** (`package.json` อยู่ในโฟลเดอร์นี้)
3. ให้ไฟล์ `src/components/group-sports/GroupSportsDashboard.tsx` ถูกแทนที่
4. Commit และ Push ผ่าน GitHub
5. ตรวจ Vercel **Preview** ก่อน Production

**ไม่ต้องรัน SQL Migration ใหม่ ไม่ต้องแก้ Environment Variables**

## ตรวจทดสอบหลัง Deploy

1. หน้า `/group-sports` แสดง 8 เมนูหลัก โดย `จัดการแข่งขัน` อยู่ตำแหน่งที่ 3
2. กด `จัดการแข่งขัน` → แผงเมนูย่อยกางลงอย่างนุ่มนวล
3. เลือกแต่ละรายการ → แสดงหน้าที่ถูกต้องในหน้าเดิม และเมนูรวมยังคงเน้นสีน้ำเงินเข้ม
4. เปิดเมนูซ้ำ → มีไฮไลต์เมนูย่อยปัจจุบัน
5. เปลี่ยนไปเมนูอื่น → ปิดแผงเมนูย่อย
6. ทดสอบหน้าจอมือถือ และตรวจสิทธิ์ผู้ดูแล/โรงเรียนตามเดิม

## การตรวจสอบในสภาพแวดล้อมจัดทำ

- ตรวจไวยากรณ์ TypeScript/TSX ด้วย TypeScript Parser ทั้ง **64 ไฟล์** ผ่าน
- ตรวจแผงเมนูย่อยทั้ง 3 รายการและโค้ดแสดงผลเดิมด้วยการตรวจแบบ static ผ่าน
- **ยังไม่ได้ทดสอบ `npm run build` เต็มรูปแบบ หรือทดสอบกับ Supabase จริง** เนื่องจากไม่มี dependencies ในสภาพแวดล้อมนี้
