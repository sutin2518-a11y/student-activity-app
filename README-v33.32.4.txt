สิ่งที่เปลี่ยน
- ปุ่ม/แท็บ “ลงทะเบียนนักกีฬา” เปิดภายในหน้าจัดการของกีฬานั้นโดยตรง
- ฝังแบบฟอร์มลงทะเบียนกลางเดิมไว้ในแท็บของแต่ละกีฬา
- แสดงใบสมัครที่ส่งแล้วและปุ่มดูรายชื่อ / พิมพ์ใบสมัคร
- เลือกเฉพาะรายการแข่งขันของกีฬานั้น ลดโอกาสเลือกผิดกีฬา
- ปรับความสูงของพื้นที่แบบฟอร์มอัตโนมัติ ไม่ต้องเลื่อนในกรอบ iframe ซ้อน
- ศูนย์ลงทะเบียนกลางจะพาไปยังหน้ากีฬาที่ถูกต้อง

การรักษาข้อมูล
- ใช้ฐานข้อมูลและระบบลงทะเบียนกลางเดิม
- ไม่สร้างตาราง Supabase ใหม่
- ไม่แก้ SQL Migration, RLS, .env.local หรือข้อมูลใบสมัครเดิม
- ฟุตบอล ฟุตซอล และบาสเกตบอลไม่ถูกเปลี่ยนฟอร์มเดิม

วิธีติดตั้ง
1. เปิดโฟลเดอร์โปรเจกต์ D:\ระบบ\student-activity-app
2. ตรวจสอบก่อนว่าได้ commit หรือสำรองงานปัจจุบันแล้ว และรัน `git status --short`
3. แตก ZIP นี้ลงในโฟลเดอร์โปรเจกต์ โดยให้รวมโฟลเดอร์ `src` และ `tests` เข้ากับของเดิม
4. เปิด Terminal ที่โฟลเดอร์โปรเจกต์ แล้วรัน:
   node apply-v33.32.4.cjs
5. หากขึ้น `OK: ปรับหน้าลงทะเบียนทั้ง 7 กีฬาเป็น v33.32.4 แล้ว` ให้รัน:
   node --test tests/registration-embed-v33.32.4.test.mjs
   npm run build
6. เมื่อ build ผ่าน ให้รัน `npm run dev` และทดสอบหน้าลงทะเบียนทั้ง 7 กีฬา
7. หลังตรวจสอบหน้าจอและการบันทึกจริงเรียบร้อยแล้ว จึง Commit และ Push ผ่าน GitHub Desktop

ข้อควรทราบ
- ต้องเข้าสู่ระบบด้วยบัญชีโรงเรียนที่ได้รับสิทธิ์ลงทะเบียน จึงจะเห็นแบบฟอร์มกรอกข้อมูล
- หากยังไม่เข้าสู่ระบบ ระบบจะแสดงปุ่มเข้าสู่ระบบโรงเรียน
- หากสคริปต์แจ้ง `STOP` อย่าฝืนแก้หรือคัดลอกไฟล์ทับ ให้ส่งภาพข้อความ STOP มาเพื่อตรวจสอบเวอร์ชันไฟล์ก่อน
- สคริปต์ตรวจสอบตำแหน่งแก้ไขทั้งหมดก่อนเขียนไฟล์ หากจุดอ้างอิงไม่ตรง จะหยุดโดยไม่แก้ไฟล์ใด ๆ
- สคริปต์ไม่ทำ Git commit / push ให้โดยอัตโนมัติ
