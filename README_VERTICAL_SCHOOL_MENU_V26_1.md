# Group Sports v26.1 — Vertical dropdown hotfix

อัปเดตจาก v26: เปลี่ยนเฉพาะเมนูย่อย "ข้อมูลสำหรับโรงเรียน" จากตาราง 3 คอลัมน์ เป็นดรอปดาวน์แนวตั้งแบบลอยใต้ปุ่มหลัก

## สิ่งที่เปลี่ยน
- เมนูย่อย 6 รายการเรียงแนวตั้งเหมือนเมนูตัวอย่าง: ส่งข้อมูลโรงเรียน (พิธีเปิด), แผนผังการยืนขบวนในสนาม, อัฒจันทร์กองเชียร์, ลำดับขบวน, จุดตั้งขบวน, ประกาศและเอกสารอื่น ๆ
- ไม่ดันเนื้อหาหน้าลง เพราะดรอปดาวน์ซ้อนเป็นชั้นเหนือเนื้อหา
- แสดงเมนูปัจจุบันเป็นแดงเข้ม พร้อมเส้นเน้นสีทอง
- เปิด/ปิดแบบนุ่มนวล ปิดเมื่อเลือกรายการหรือคลิกภายนอก และรองรับปุ่ม Escape
- จัดแนวดรอปดาวน์ให้ตรงกับปุ่มแม้เมนูด้านบนเลื่อนในจอแคบ

## วิธีติดตั้ง (Patch)
1. ใช้กับโครงการ v26 ที่ติดตั้งแล้ว
2. แตก ZIP และคัดลอกไฟล์ `src/components/group-sports/GroupSportsDashboard.tsx` ทับไฟล์เดิมด้วยตำแหน่งโฟลเดอร์เดียวกัน
3. เปิด GitHub Desktop > Commit (`Group sports vertical school info dropdown v26.1`) > Push origin
4. ทดสอบ Vercel Preview: เปิดเมนูข้อมูลสำหรับโรงเรียน, เลือกทั้ง 6 หัวข้อ, ปิดด้วย Escape, คลิกนอกเมนู และทดสอบมือถือ

ไม่ต้องรัน SQL Migration หรือเพิ่ม Environment Variables
