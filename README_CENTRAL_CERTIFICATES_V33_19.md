# v33.19 — พิมพ์เกียรติบัตรส่วนกลาง

ฐาน: ZIP โปรเจค(1).zip (v33.18) วันที่ 24 พ.ย. 2569

## สิ่งที่เปลี่ยน
- เพิ่ม `/group-sports/certificates/central` สำหรับกรรมการพิมพ์ส่วนกลางและแม่แอดมิน แยกจากหน้าพิมพ์โรงเรียน `/group-sports/certificates` และหน้าบันทึกผล `/group-sports/results`.
- เลือกรายการแข่งขัน แล้วกรองโรงเรียน ประเภทเกียรติบัตร นักกีฬา/ครู และค้นหาชื่อหรือเลขที่ เลือกหลายฉบับและพิมพ์/บันทึก PDF ผ่านเบราว์เซอร์โดยใช้แม่แบบเดิมและ QR เดิม.
- พิมพ์เฉพาะเอกสารที่ออกแล้วและไม่ถูกเพิกถอน ตรวจสิทธิ์และรายการล่าสุดอีกครั้งก่อนกดพิมพ์ ไม่ออกเอกสารใหม่ ไม่แก้ผล ไม่เปลี่ยนสิทธิ์โรงเรียน.
- แม่แอดมินมอบหมายหรือระงับกรรมการพิมพ์ส่วนกลางด้วยอีเมล Google ที่หน้า central (แผงมอบหมายพับเก็บได้) ไม่ให้สิทธิ์บันทึกผลโดยอัตโนมัติ.
- เมนูระบบแสดงลิงก์ central เฉพาะผู้มีสิทธิ์ และ auth callback ส่งกรรมการส่วนกลางเข้าสู่หน้านี้เมื่อไม่มีบทบาทกีฬาอื่นที่มีลำดับเดิมก่อนหน้า.
- `/group-sports/officials` และ `/group-sports/certificates/officials` ใช้ SportsOfficialsAccessManager ตัวเดียวกัน แสดงข้อความข้อผิดพลาด RPC ที่อ่านได้มากขึ้น.
- ไม่เปลี่ยนระบบกิจกรรมพัฒนาผู้เรียน และยังไม่เปิดสิทธิ์บันทึกคะแนน/แมตช์ให้กรรมการทั่วไปจาก registry 036 (งานถัดไป).

## การติดตั้ง
1. Commit สำรองโปรเจกต์ปัจจุบันก่อน แตก ZIP นี้ในโฟลเดอร์ใหม่และเทียบกับ GitHub ล่าสุด (หากมีการแก้ไขหลังส่ง ZIP อย่าทับโดยไม่ตรวจสอบ).
2. ตรวจ migration 027, 029 และ 036 ว่าติดตั้งแล้ว หาก 036 ยังไม่ติดตั้ง ให้รัน `supabase/migrations/202611240036_sports_event_referees_v33_18.sql` ก่อน.
3. รัน `supabase/migrations/202611240037_sports_central_certificate_print_v33_19.sql` ใน Supabase SQL Editor ของโปรเจกต์ที่ถูกต้อง. SQL เพิ่มตารางและ RPC เท่านั้น ไม่ลบหรือ reset ข้อมูล.
4. ใช้ `.env.local` เดิมจากเครื่องของผู้พัฒนา (ไม่เผยแพร่ secrets) ติดตั้ง dependencies ด้วย `npm ci` แล้ว `npm run build` บนเครื่องจริง. หากผ่านจึง commit/push และตรวจ Vercel.
5. แม่แอดมินเปิดเมนูระบบ > พิมพ์เกียรติบัตรส่วนกลาง > มอบหมายกรรมการพิมพ์ส่วนกลาง. กรรมการเข้าสู่ระบบ `/login` ด้วยอีเมล Google ที่ตรงกัน. ถ้ามีหลายบทบาท ใช้เมนูระบบจากหน้ากีฬากลุ่มเพื่อสลับเข้าหน้าพิมพ์.

## Checklist ทดสอบจริง
- แม่แอดมินมอบหมายและระงับสิทธิ์ได้; อีเมลอื่นและบัญชีโรงเรียนทั่วไปเข้าหน้า central/RPC ไม่ได้.
- กรรมการส่วนกลางเห็นเอกสารที่ออกแล้วจากหลายโรงเรียนในรายการเดียวกัน กรอง/เลือกหลายฉบับได้.
- เอกสารเพิกถอนไม่แสดง และการเพิกถอนระหว่างเลือกและพิมพ์ทำให้ระบบหยุดพิมพ์เพื่อให้ตรวจใหม่.
- กรรมการส่วนกลางที่ไม่ได้รับมอบหมายสิทธิ์อื่นไม่สามารถแก้ไขผลหรือจัดการโรงเรียน.
- หน้าพิมพ์โรงเรียนเดิมยังจำกัดเอกสารตามโรงเรียน, QR และแม่แบบเดิมยังใช้ได้.
- URL มอบหมายกรรมการทั้งสองเส้นทางแสดงหน้าจอเดียวกัน.
