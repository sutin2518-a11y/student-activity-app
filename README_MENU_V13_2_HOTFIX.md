# เมนูระบบกีฬากลุ่ม — Hotfix v13.2

## ปัญหาที่แก้
- คลิกเมนูหลัก “จัดการแข่งขัน” แล้วเมนูย่อยกาง แต่ปุ่มหลักไม่เปลี่ยนเป็นสีน้ำเงินเข้ม จนกว่าจะเลือกเมนูย่อย
- เมนูหน้าก่อนหน้า (เช่น “โรงเรียน”) ยังแสดงเป็นสถานะเลือกพร้อมกับเมนูจัดการแข่งขัน

## การปรับ
1. ระหว่างที่เมนูย่อยกาง จะให้ปุ่ม “จัดการแข่งขัน” มีสถานะ active และเลิกไฮไลต์เมนูก่อนหน้า
2. กำหนดสีน้ำเงินกรมท่าบนปุ่ม active โดยตรงเพื่อกันความขัดแย้งของคลาส CSS ที่ถูกแคช
3. เมื่อกดจัดการแข่งขันจากเมนูอื่น ให้แสดงหน้า “จัดการ / ดูโปรแกรม” ทันที เช่นเดียวกับ v13.1
4. เมื่อเลือกเมนูย่อย “รายการแข่งขัน” หรือ “โปรแกรม / ผล” ระบบแสดงหน้านั้นพร้อมปุ่มจัดการแข่งขันเป็นสีเข้มต่อเนื่อง
5. เพิ่ม attribute `data-menu-version="13.2"` บน nav เพื่อใช้ตรวจสอบว่าได้ Deploy ไฟล์ใหม่นี้แล้ว

## ไฟล์แก้ไข

## การติดตั้ง
1. ใช้โปรเจกต์ v13.1 อยู่แล้ว: แตก `student-activity-sports-menu-v13.2-hotfix-patch.zip` ลงรากโปรเจกต์ (โฟลเดอร์เดียวกับ `package.json`)
2. เปิด GitHub Desktop ตรวจสอบไฟล์ที่เปลี่ยน แล้ว Commit เช่น `Fix sports menu parent active highlight v13.2` และ Push
3. รอ Vercel Preview/Production ที่เป็น commit ใหม่นี้ขึ้นสถานะ Ready
4. ถ้า Preview ผ่าน ให้ Merge เข้า `main` เพื่อให้ Production อัปเดตตาม branch tracking; อย่าทดสอบจาก URL ของ deployment เก่า
5. บังคับโหลดหน้าใหม่ด้วย Ctrl+Shift+R

## การทดสอบ
- จากเมนู “โรงเรียน” กด “จัดการแข่งขัน” ครั้งเดียว: พื้นปุ่มจัดการแข่งขันเป็นน้ำเงินเข้มทันที, ปุ่มโรงเรียนกลับพื้นอ่อน, แผงเมนูย่อยกาง, เนื้อหาแสดงหน้าจัดการ / ดูโปรแกรม
- เลือก “รายการแข่งขัน”: แผงยุบ, หน้าเปลี่ยนเป็นรายการแข่งขัน, ปุ่มจัดการแข่งขันยังเป็นน้ำเงินเข้ม
- กด “จัดการแข่งขัน” ซ้ำ: แผงกลับมากาง, ปุ่มยังเป็นน้ำเงินเข้ม
- คลิก “โรงเรียน”: แผงยุบ, ปุ่มโรงเรียนเป็นน้ำเงินเข้มเพียงปุ่มเดียว

การอัปเดตนี้ไม่เกี่ยวข้องกับ Supabase, SQL Migration หรือ Environment Variables

การทดสอบโค้ด: TypeScript TSX parser / transpilation และ regression checks ของ state ผ่าน แต่ยังไม่ได้ทดสอบ Production Build กับ dependency จริง
