# ระบบกีฬากลุ่ม v22 — แนบรูป RoV จากใบสมัครเดิม

## ปัญหา
หน้าลงทะเบียนที่อยู่ด้านบนเป็นใบสมัคร **ใหม่** จึงไม่แสดงรายชื่อที่ส่งแล้วอัตโนมัติ การเรียก `sports_roster_details` ผ่านปุ่ม "ดูรายชื่อ" เดิม หากตอบกลับผิดพลาดจะแสดงข้อความด้านบนของหน้าจอ ผู้ใช้จึงไม่เห็นว่าเกิดอะไรขึ้น และไม่พบตำแหน่งแนบรูป

## แก้ไข
- เพิ่มปุ่ม **ไปที่ใบสมัครเดิม** ในฟอร์มใหม่ เพื่อปิดฟอร์มและพาไปยังใบสมัครที่บันทึกไว้
- เพิ่มปุ่ม **แนบรูปใบสมัครเดิม** ต่อท้ายรายการ RoV เฉพาะผู้มีสิทธิ์ของโรงเรียน
- ปุ่มใหม่ใช้ `sports_roster_details` เดิม (ตรวจสิทธิ์โรงเรียนโดย Supabase) ดึงรายชื่อจริง ไม่เริ่มลงทะเบียนซ้ำ
- เมื่อดึงสำเร็จ เลื่อนลงไปยังแผงรูปนักกีฬา 1–7 โดยอัตโนมัติ
- เมื่อดึงไม่สำเร็จ แสดงข้อความผิดพลาด **ข้างรายการใบสมัคร** พร้อมแนวทางตรวจสอบ
- ยังคงปุ่ม "ดูรายชื่อ" และ "พิมพ์ใบสมัคร PDF" เดิม
- ไม่มีการแก้ไข SQL, RLS, Storage หรือข้อมูลใบสมัคร

## วิธีติดตั้ง
1. ใช้โครงการ **v21** ซึ่งติดตั้ง SQL Migration 0016 และ 0017 แล้ว
2. แตก Patch ZIP ไปทับโครงสร้างโครงการ โดยมีไฟล์แก้เพียง:
   `src/components/group-sports/GroupSportsDashboard.tsx`
3. Commit และ Push ผ่าน GitHub Desktop แล้วทดสอบ Vercel Preview ด้วยฐานข้อมูลทดสอบ หรือ Production หลังตรวจสอบ
4. เข้าระบบด้วยบัญชีโรงเรียนเจ้าของใบสมัคร → ลงทะเบียน → ไปที่ใบสมัครเดิม → แนบรูปใบสมัครเดิม
5. เลือกภาพ JPG/PNG/WebP รายคน แล้วตรวจหน้า PDF ที่พิมพ์ใหม่

## ถ้ารายชื่อยังไม่ขึ้น
บันทึกข้อความสีแดงใต้รายการใบสมัคร (รวมรหัสข้อผิดพลาดจาก RPC) เพื่อตรวจสอบสิทธิ์ `school_manager` และการทำงานของ `sports_roster_details` โดยไม่ลงทะเบียนซ้ำหรือเปลี่ยน SQL แบบเดาสาเหตุ

## การทดสอบและข้อจำกัด
- ตรวจ syntax ของไฟล์ TS/TSX ในโครงการ 69 ไฟล์ด้วย TypeScript transpiler ผ่าน
- ยังไม่ได้รัน Production Build (ไม่มี node_modules ในสภาพแวดล้อมนี้) หรือทดสอบเชื่อมต่อ Supabase จริง
- ไม่ใช่การเปลี่ยนวิธีบันทึกนักกีฬาหรือแก้ไขใบสมัครเดิม
