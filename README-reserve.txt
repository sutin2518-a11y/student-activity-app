อัปเดตตะกร้อและบาสเกตบอล — นักกีฬาเพิ่มเติมไม่บังคับ (ต่อจาก optional staff v2)

ใช้หลัง SQL 054 v2 แสดง READY ทั้งสองกีฬาแล้วเท่านั้น ไม่ต้องรัน SQL เพิ่ม
สำรองไฟล์และตรวจว่าทั้งสอง Component ไม่มีการแก้เพิ่มเติมจาก v2 ในเครื่องก่อนวางทับ
คัดลอก src ไปวางในรากโปรเจกต์ student-activity-app
มี Component ที่ปรับเพิ่ม 2 ไฟล์ และหน้า print ตะกร้อจาก v2 เดิม (ไม่เปลี่ยน) เพื่อให้ชุดนี้ใช้ได้แม้ยังไม่ได้วาง src ของ v2
คงเงื่อนไขเจ้าหน้าที่ v2: ผู้ฝึกสอนอย่างน้อย 1 คน ผู้จัดการ/ผู้ช่วยไม่บังคับ
ตะกร้อ: อย่างน้อย 3 คน สูงสุด 5; แถว 4–5 ว่างได้
บาสเกตบอล: อย่างน้อย 7 คน สูงสุด 12; แถว 8–12 ว่างได้
แถวเพิ่มเติมที่ว่างทั้งหมดไม่ส่งไป RPC; หากกรอกบางส่วนหรือแนบรูป ต้องกรอกข้อมูลบังคับของนักกีฬาคนนั้นให้ครบ
ใช้รายชื่อที่ผ่านการกรองชุดเดียวกับการแนบรูป ไม่ใช้แถวว่างเป็นตำแหน่งในฐานข้อมูล
ไม่เปลี่ยน SQL หรือสิทธิ์ ไม่เพิ่มสิทธิ์แก้ไข/ถอนใบสมัคร ไม่เปลี่ยนเงื่อนไขจำนวนขั้นต่ำ

ทดสอบ npm run build แล้ว npm run dev (ใช้ฐานทดสอบเพื่อไม่เพิ่มใบสมัครทดลองใน Production)
- ทดสอบจำนวนขั้นต่ำและเจ้าหน้าที่ 1 คน
- เพิ่มแถวว่าง 1–2 แถว และทดสอบส่ง; ตรวจจำนวนที่บันทึก
- เว้นแถวเพิ่มเติมกลางไว้ และกรอกอีกแถวพร้อมรูป ตรวจรูปตรงกับชื่อหลังบันทึก
- กรอกแถวเพิ่มเติมบางส่วน ระบบต้องไม่ละทิ้งข้อมูลเงียบ ๆ
- ทดสอบกรอกไม่ครบจำนวนขั้นต่ำ ต้องส่งไม่ผ่าน
- ตรวจพิมพ์ใบสมัครและดูใบสมัครเดิม ก่อน Commit/Push
ตรวจ syntax ด้วย TypeScript transpileModule และทดสอบตัวกรองแถวแล้ว ยังไม่ได้ build เต็ม/ทดสอบ Supabase จริง
