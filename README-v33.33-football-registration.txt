สิ่งที่เพิ่ม
- ฟอร์มสมัครฟุตบอลทั้ง 4 รุ่น แนบรูปนักกีฬาและเจ้าหน้าที่รายคนพร้อมดูตัวอย่าง รองรับ JPG/PNG/WebP <=5MB; แปลง JPG ด้วยตัวช่วยเดิม ก่อนอัปโหลดเข้าพื้นที่ private เดิม
- บันทึกใบสมัครก่อนอัปโหลดรูป และตรวจชื่อ/รหัสนักเรียน/ลำดับกับข้อมูลที่อ่านกลับก่อนแนบ หากบางรูปผิดพลาดยังเก็บใบสมัครและกลับมาแนบใหม่ได้
- แสดงชื่อและรูปผู้จัดการทีม ผู้ฝึกสอน ผู้ช่วยผู้ฝึกสอนแยกตามตำแหน่ง; เก็บชื่อผู้จัดการทีมครบตั้งแต่สร้างใบสมัครใหม่
- ใบสมัครที่บันทึกแล้ว: แนบ/เปลี่ยน/ลบรูปอย่างเจาะจง และส่งออกรูปของใบสมัครเป็น ZIP พร้อม manifest.json แจ้งรูปที่ดาวน์โหลดไม่ได้
- Admin ส่งออก Excel 4 รุ่น + สรุป + เจ้าหน้าที่ (6 ชีต) โดยใช้ RPC เดิมตามสิทธิ์; path ใน Excel เป็นที่อยู่ที่คาดไว้ ไม่รับรองว่ารูปมีอยู่จริง; ไม่ใช่ database dump และไม่รวมไฟล์รูปจริง
- PDF A4 ขาวดำตาม 4 ภาพต้นฉบับ: หน้า 1 รายชื่อ 20 แถว; หน้า 2 ใบส่งรายชื่อ; หน้า 3 12 รูป; หน้า 4 8 รูปและ 4 เจ้าหน้าที่
- คงข้อแตกต่างเดิมของรุ่นชายไม่จำกัดอายุ (22 แถว P/S/N ตามแม่แบบเฉพาะรุ่นที่เคยพัฒนา ไม่รับสมัครเกิน 20 คน) และเอกสารแนบเพิ่มหากเจ้าหน้าที่เกิน 4 คน
- อายุเป็นจำนวนปีเต็ม ณ วันเริ่มแข่ง ไม่ใช้ตัดสินสิทธิ์ตามกติกา; รูปที่ยังไม่มีเว้นกรอบว่าง ไม่บล็อกการบันทึกรายชื่อ

การติดตั้ง (เฉพาะระบบฟุตบอล)
1. ตรวจว่าอยู่บน branch main และสำรองงานล่าสุดใน GitHub Desktop; อย่าทับโปรเจกต์ทั้งก้อน
2. สำรองฐานข้อมูลและไฟล์รูปเดิมก่อน (โดยเฉพาะ sports_entries, sports_athletes, sports_roster_staff, sports_football_player_details, private Storage) การส่งออก Excel ไม่ใช่การกู้ฐานข้อมูลครบถ้วน
3. แตก ZIP นี้และคัดลอกเนื้อหาภายในทับที่ root ของ student-activity-app (โฟลเดอร์ที่มี package.json) โดยคง path เดิม
4. Supabase SQL Editor: เปิดไฟล์ supabase/migrations/202611250048_sports_football_registration_v33_33.sql แล้วรันทั้งไฟล์หนึ่งครั้ง; รอ Success. No rows returned
   Migration เพิ่ม RPC ฟุตบอลใหม่และ policy ลบรูปฟุตบอลเฉพาะผู้มีสิทธิ์ ไม่รีเซ็ตข้อมูล ไม่แก้ RPC กลาง ไม่เปลี่ยนสถานะเปิดรับสมัคร
5. เปิด Terminal ที่ root (ถ้า dev รันอยู่ ให้หยุด Ctrl+C ก่อน) แล้วรัน
   npm run build
   npm run dev
6. เปิด http://localhost:3000/group-sports/football?tab=registration
   ใช้บัญชีโรงเรียนที่มีสิทธิ์และรุ่นที่เปิดรับสมัคร; ทดสอบด้วยข้อมูลทดลองในสภาพแวดล้อมทดสอบ หากจำเป็นต้องทดสอบจริงควรใช้ใบสมัครจริงที่ได้รับอนุญาต ไม่สร้างหรือแก้ข้อมูลโรงเรียนอื่น
   - เลือกรูปนักกีฬา/เจ้าหน้าที่ก่อนกดส่ง ตรวจชื่อผู้จัดการทีมหลังเปิดใบสมัครเดิม
   - ตรวจรูปหลังบันทึก เปลี่ยนรูปได้ (ลบเฉพาะรูปที่เลือกด้วยการยืนยัน)
   - พิมพ์ PDF ขนาด A4 แนวตั้ง 4 หน้า (ยกเว้นเจ้าหน้าที่เพิ่มเติม) ปิด headers/footers ของ browser; ตรวจรูปและชื่อทุกคน
   - Admin ดาวน์โหลด Excel ตรวจจำนวนใบสมัครและนักกีฬาแต่ละรุ่น; ZIP รูปเปิดจากใบสมัครแต่ละทีมและตรวจ manifest.json
   - ทดสอบบัญชีอีกโรงเรียนและผู้เข้าชมว่าเข้าถึงใบสมัคร/รูปต่างโรงเรียนไม่ได้
7. หาก Build และทดสอบผ่าน Commit ชื่อ v33.33 - Football registration photos and official forms แล้ว Push origin; ตรวจ Vercel Preview/Production Ready และทดสอบหลัง Deploy
