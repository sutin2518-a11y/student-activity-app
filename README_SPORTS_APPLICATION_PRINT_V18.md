# ระบบพิมพ์ใบสมัครกีฬากลุ่ม (v18) — แบบพิมพ์ RoV ฉบับย่อ

ปรับจากโครงการ v17 โดยเพิ่มปุ่มพิมพ์ใบสมัคร และหน้า `/group-sports/print?entry=<UUID>` สำหรับพิมพ์ A4 / Save as PDF ผ่านเบราว์เซอร์ โดยตรวจสิทธิ์ผู้ใช้ที่ล็อกอินก่อนอ่านใบสมัคร

## รูปแบบ RoV ฉบับย่อ

พิมพ์เฉพาะชื่อการแข่งขัน โรงเรียน รายการแข่งขัน รายชื่อและประเภทนักกีฬา (ตัวจริง/ตัวสำรอง) รายชื่อครูผู้ควบคุมทีม และช่องลงนามรับรองครู/ผู้อำนวยการโรงเรียน

**ไม่พิมพ์** รหัสนักเรียน ชื่อในเกม IGN ตำแหน่งการเล่น เบอร์โทรศัพท์ครู สถานะรายการ หรือ UUID ของใบสมัครบนกระดาษ โดยข้อมูลทั้งหมดนั้นยังเก็บในฐานข้อมูลเดิม ไม่มีคำสั่งลบหรือแก้ไขข้อมูลดังกล่าว

## ประเภทอื่น

กีฬาทีม กีฬาเดี่ยว/คู่ และกรีฑา ยังคงแบบฟอร์มฉบับละเอียดที่แสดงรหัสนักเรียน รายชื่อครู และช่องลงนาม รองรับการแบ่งหน้า A4 เมื่อมีรายชื่อจำนวนมาก

## ใช้งาน

1. ล็อกอินด้วยบัญชีโรงเรียนหรือผู้ดูแลที่มีสิทธิ์ดูใบสมัคร
2. เปิดเมนู ลงทะเบียน เลือกใบสมัครที่ส่งแล้ว แล้วกด **พิมพ์ใบสมัคร PDF**
3. ตรวจรายการในหน้าตัวอย่าง แล้วกด **พิมพ์ / บันทึก PDF**
4. เลือก `Save as PDF` ใน Chrome/Edge และเลือก A4

## จุดที่ควรทดสอบก่อนใช้งานจริง

- RoV 5–7 คน พิมพ์ A4 หน้าเดียว ครู 1–3 คนและช่องลงนามครบ
- กีฬาทีม 20 คน พิมพ์หลายหน้าได้โดยตารางไม่ถูกตัดกลางแถว
- โรงเรียนหนึ่งพยายามเปิดใบสมัครของอีกโรงเรียน ต้องถูกปฏิเสธ
- บัญชีที่ไม่ได้ล็อกอินจะไม่เห็นข้อมูลนักกีฬา
- รายละเอียด IGN, รหัสนักเรียน, ตำแหน่งที่เล่นและเบอร์ครูยังอยู่ในหน้าแสดงหลักฐานของระบบ
