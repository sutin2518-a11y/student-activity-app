# Sports group menu hotfix v13.1

แก้บั๊กเมนู **จัดการแข่งขัน** ใน GroupSportsDashboard.tsx ที่กดแล้วเปิดเมนูย่อยแต่ยังแสดงหน้าเดิม

- หากคลิกจากเมนูหลักอื่น: เลือกแท็บ `schedule` (จัดการ / ดูโปรแกรม) พร้อมเปิดเมนูย่อยทันที
- หากอยู่ภายในกลุ่มจัดการแข่งขันแล้ว: คลิกเพื่อขยายหรือยุบเมนูย่อย โดยไม่เปลี่ยนแท็บที่เลือก
- ปุ่มหลักแสดงสีกรมท่าเมื่อเมนูย่อยกางอยู่หรือเนื้อหาอยู่ในกลุ่มจัดการแข่งขัน; คงเอฟเฟกต์ขอบเรืองแสงและแถบทอง
- เมื่อเลือกเมนูย่อย `รายการแข่งขัน` หรือ `โปรแกรม / ผล` เนื้อหาเปลี่ยนและปุ่มหลักยังคงสถานะ active

## ติดตั้ง

แตก Patch ทับรากโปรเจกต์ v13 ซึ่งมีโฟลเดอร์ `src/` อยู่แล้ว แล้ว Commit/Push ขึ้น GitHub เพื่อทดสอบบน Preview ก่อน Production

ไฟล์ที่เปลี่ยน: `src/components/group-sports/GroupSportsDashboard.tsx`
ไม่มี SQL migration หรือ Environment Variable เพิ่ม

## การทดสอบ

ตรวจ syntax และ transpile TSX ผ่าน; ไม่ได้รัน `next build` เต็มรูปแบบในสภาพแวดล้อมนี้ (แพ็กเกจ Next.js ใน node_modules ไม่ครบ) จึงแนะนำให้ดู Vercel Build Logs หลัง Push

## กรณีทดสอบในเว็บ

1. เริ่มจากแท็บ โรงเรียน, กด จัดการแข่งขัน → ปุ่มหลักเป็นน้ำเงินเข้ม / เปิดแผงย่อย / เนื้อหาเปลี่ยนไปเป็น จัดการ / ดูโปรแกรม
2. เลือก รายการแข่งขัน → แผงย่อยยุบ / เนื้อหารายการแข่งขันแสดง / ปุ่มหลักยังเป็นน้ำเงินเข้ม
3. คลิก จัดการแข่งขัน อีกครั้ง → แผงย่อยกาง แต่ยังคงหน้ารายการแข่งขันเดิม
4. กดเมนู โรงเรียน → กลับไปหน้าโรงเรียน / แผงย่อยยุบ / ไฮไลต์ย้ายไปเมนูโรงเรียน
