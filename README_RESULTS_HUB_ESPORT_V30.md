# v30 – หน้าศูนย์รวมผลการแข่งขัน + ทางเข้าระบบ E-Sport

## เปลี่ยนอะไร

- เมนูย่อย `จัดการแข่งขัน → โปรแกรม / ผล` เปลี่ยนเป็น **ผลการแข่งขัน**
- หัวหน้าผลการแข่งขันเปลี่ยนจาก “โปรแกรมและผลการแข่งขัน” เป็น **ผลการแข่งขัน**
- หน้าเดียวรวมชนิดกีฬา โดยแสดงการ์ดเลือกชนิดกีฬาที่สร้างจากรายการกีฬาในฐานข้อมูลจริง และตัวกรองรุ่น / ประเภท
- มีการ์ด **E-Sport (RoV)** เป็นปุ่มลิงก์ตรงไปยัง `/group-sports/esports` แม้ยังไม่มีรายการที่เผยแพร่
- ผู้ชมสามารถดูผลประเภททีม รวมถึงผลประเภทเดี่ยว/กรีฑาในหน้าผลการแข่งขัน
- จากหน้า E-Sport กดกลับไปยัง `/group-sports?section=results` ได้
- ลิงก์ `ดูโปรแกรมทั้งหมด` บนหน้าแรก เปลี่ยนให้ไปแท็บจัดการ/ดูโปรแกรมตามเจตนา ไม่ใช่หน้าผล

## สิทธิ์กรรมการ E-Sport (สำคัญ)

ลิงก์นี้ทำให้ **เปิดหน้า E-Sport** ได้เท่านั้น ไม่ได้มอบสิทธิ์แก้ไขผลแข่งขัน
หน้า E-Sport และ RLS Supabase เดิมใช้ RPC `sports_stage3_admin(competition_id)` เพื่อตรวจสิทธิ์บันทึก/แก้ไขข้อมูล
หากกรรมการกีฬายังไม่มีสิทธิ์ ให้ผู้ดูแลกำหนดบทบาทที่ระบบรองรับให้ก่อน ห้ามเปิด RLS เป็นสาธารณะเพื่อแก้ไข

## ติดตั้งจาก v29 complete

1. สำรองโครงการและแตก Patch v30 ทับ โดยคงโครงสร้างโฟลเดอร์
2. Commit → Push และตรวจ Vercel Preview
3. ทดสอบ `จัดการแข่งขัน → ผลการแข่งขัน → E-Sport (RoV)` และกดลิงก์กลับ
4. ทดสอบการดูผล/กรองกีฬา/รุ่น และการบันทึกผลด้วยบัญชีผู้ดูแลที่ได้รับสิทธิ์

**ไม่ต้องรัน SQL** เพราะเปลี่ยนหน้าเว็บและทางเข้าระบบเท่านั้น

## ข้อจำกัดการตรวจ

ผ่านการตรวจไวยากรณ์ TypeScript/TSX ด้วย parser อิสระเท่าที่สภาพแวดล้อมรองรับ แต่ยังไม่ได้ทดสอบ Next.js Production Build และ Supabase จริง
