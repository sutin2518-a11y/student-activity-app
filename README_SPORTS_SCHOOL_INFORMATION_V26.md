# ระบบกีฬากลุ่ม v26 — ข้อมูลสำหรับโรงเรียนและงานพิธีเปิด

## สิ่งที่เปลี่ยน
- เปลี่ยนปุ่มหลัก **ส่งข้อมูลโรงเรียน** เป็น **ข้อมูลสำหรับโรงเรียน** (ดรอปดาวน์พร้อมเอฟเฟกต์กางลง)
- เมนูย่อย 6 รายการ: (1) ส่งข้อมูลโรงเรียน (พิธีเปิด), (2) แผนผังการยืนขบวนในสนาม,
  (3) อัฒจันทร์กองเชียร์, (4) ลำดับขบวน, (5) จุดตั้งขบวน, (6) ประกาศและเอกสารอื่น ๆ
- เมนูส่งข้อมูลโรงเรียนเดิมยังเรียก `SchoolSubmissionsContent` พร้อมรายงาน 21 โรงเรียนได้เหมือนเดิม
- กรรมการที่มีสิทธิ์ `competition_admin` หรือ `super_admin` สร้าง/แก้ไขรายการและแนบเอกสาร PDF/JPG/PNG/WebP (ไม่เกิน 12MB)
- ทุกประกาศบันทึกเป็น **ฉบับร่างก่อน**; เมื่อกรรมการกด **เผยแพร่ให้โรงเรียนเห็น** จึงเปิดให้ทุกโรงเรียนอ่าน/ดาวน์โหลด
- แสดงเฉพาะประกาศที่เผยแพร่; ถอนเผยแพร่ได้; ไฟล์ถูกเก็บใน Storage แบบ Private พร้อมลิงก์อายุ 10 นาที
- สีแดง–ขาวเดิม, ไม่แตะระบบนักกีฬา, รูปถ่าย, พิมพ์ PDF, บัญชีโรงเรียนหรือขั้นตอนส่ง Word

## ขั้นตอนติดตั้ง
1. สำรองฐานข้อมูล Supabase ก่อน
2. รัน `supabase/migrations/202611220021_sports_school_information_hub.sql` ใน SQL Editor หลังจาก Migration 0020
3. แตกไฟล์ Patch v26 ทับโครงการ v25 โดยรักษาโครงสร้างโฟลเดอร์
4. Commit และ Push บน GitHub Desktop; ทดสอบบน Vercel Preview โดยใช้ฐานข้อมูล **ทดสอบ** หรือ Production อย่างระมัดระวัง
5. เข้าเมนู `ข้อมูลสำหรับโรงเรียน > แผนผังการยืนขบวนในสนาม` ด้วยผู้ดูแลการแข่งขัน
6. ใส่หัวข้อ รายละเอียด แนบรูป/PDF เอกสารข้อมูลเบื้องต้น แล้วกด **บันทึกฉบับร่าง**
7. ตรวจสอบความถูกต้องและความเป็นทางการของแผนผัง/ตำแหน่งต่าง ๆ ก่อนกดเผยแพร่
8. เปิดเว็บในมุมโรงเรียนเพื่อยืนยันว่าเห็นเฉพาะข้อมูลที่เผยแพร่

## ข้อควรทราบ
- ภาพข้อมูลเบื้องต้นที่ส่งในแชทไม่ได้อัปโหลดไป Supabase อัตโนมัติ: ผู้ดูแลนำไฟล์ต้นฉบับไปแนบในเมนูที่ตรงประเภทหลัง Deploy
- อย่าเผยแพร่ข้อมูลสถานที่/ลำดับที่ยังไม่ยืนยัน; ใช้สถานะฉบับร่างก่อน
- แนะนำไฟล์ PDF สำหรับแผนผังที่ต้องพิมพ์ และ PNG/JPEG สำหรับภาพดูบนมือถือ
- ระบบเก็บประกาศได้หลายรายการต่อหัวข้อ เหมาะสำหรับฉบับแก้ไขและประกาศเปลี่ยนแปลง
- RLS ตรวจสิทธิ์ฐานข้อมูลและ Storage ไม่อาศัยเพียงปุ่มที่ซ่อนบนหน้าเว็บ
- ไม่ต้องตั้ง Environment Variable เพิ่ม และไม่มีการเปลี่ยนเงื่อนไขรับสมัครนักกีฬา

## ขอบเขตการตรวจสอบ
ไฟล์ TS/TSX ผ่านการตรวจไวยากรณ์โดย TypeScript transpiler แต่ยังไม่ได้รัน Production Build เต็มหรือทดสอบกับ Supabase จริง เนื่องจากแพ็กเกจ npm ของโครงการไม่ได้ติดตั้งครบในสภาพแวดล้อมนี้
