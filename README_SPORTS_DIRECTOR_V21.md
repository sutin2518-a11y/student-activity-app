# ระบบกีฬากลุ่ม v21 — ผู้อำนวยการ/ผู้จัดการทีม และสนามแข่งขันใน PDF

อัปเดตจาก **v20 (ระบบแนบรูป RoV)** โดยไม่ลบใบสมัครเดิม ไม่เปลี่ยนรายชื่อนักกีฬา และไม่กระทบระบบกิจกรรมหลัก

## เพิ่มอะไร

1. เมนู **โรงเรียน**: ผู้ดูแลการแข่งขันหรือบัญชี `school_manager` ของโรงเรียนนั้นสามารถกรอกคำนำหน้าและชื่อ–สกุลผู้อำนวยการได้ในทะเบียนโรงเรียน. เรียก RPC `sports_set_school_director` ซึ่งตรวจสิทธิ์ฝั่งฐานข้อมูล ไม่เปิดสิทธิ์ให้โรงเรียนอื่นแก้ข้อมูล
2. หน้า **พิมพ์ใบสมัคร RoV**: ตารางแถว 1 “ผู้จัดการทีม” แสดงชื่อผู้อำนวยการอัตโนมัติ และหน้า 2 เติมชื่อใต้ช่องลงนาม
3. ช่อง **ณ**: ใช้ `sports_events.venue_name` ของรายการแข่งขัน โดย RoV ใช้ “หอประชุม โรงเรียนเชียงคำวิทยาคม” เป็นค่าเริ่มต้นหากยังไม่ได้กำหนด
4. กีฬาอื่น: PDF แสดงสถานที่แข่งขันและชื่อผู้อำนวยการในส่วนสรุป/ช่องลงนาม
5. แก้การแสดงชื่อโรงเรียนที่เคยซ้ำว่า `โรงเรียน โรงเรียน...`
6. ข้อมูลเก่า: ใบสมัครที่มีอยู่ไม่ต้องลงทะเบียนใหม่ เมื่อเปิดหน้าพิมพ์ครั้งแรกหลังระบุผู้อำนวยการ จะบันทึกชื่อเป็น **snapshot** ใน `sports_entries.director_name_snapshot` ให้ชื่อในใบสมัครเดิมไม่เปลี่ยนตามทะเบียนในอนาคต ส่วนใบสมัครใหม่รับ snapshot ตั้งแต่สร้าง

## ติดตั้ง

1. **สำรองฐานข้อมูลและตรวจการอัปเดต v20 / Migration 0016** ก่อน
2. รัน `supabase/migrations/202611220017_school_director_and_print_venue.sql` ใน Supabase SQL Editor เพียงครั้งเดียว
3. คัดลอกไฟล์จาก Patch v21 ลงในโครงการเดิมโดยคงโฟลเดอร์ต้นทาง:
   - `src/components/group-sports/SchoolDirectorEditor.tsx` (ไฟล์ใหม่)
   - `src/components/group-sports/GroupSportsDashboard.tsx`
   - `src/components/group-sports/SchoolSubmissionsContent.tsx` (คำอธิบายแยกข้อมูลพิธีเปิด)
   - `src/app/group-sports/print/page.tsx`
4. Commit และ Push ไป GitHub; ทดสอบ Vercel **Preview** ก่อน Production
5. เปิดเมนู **โรงเรียน**, เลือกโรงเรียนของบัญชี, กด **แก้ไขชื่อผู้อำนวยการ**, กรอกข้อมูลและบันทึก
6. เปิดรายการ RoV เดิมในเมนูลงทะเบียน → **พิมพ์ใบสมัคร PDF** และตรวจว่าแถว 1, แถวลายเซ็น และ `ณ หอประชุม โรงเรียนเชียงคำวิทยาคม` แสดงถูกต้อง

## ข้อควรทราบ

- **ยังไม่ได้ Deploy/รัน SQL จริง** ต้องติดตั้งก่อนเริ่มใช้
- ชื่อผู้อำนวยการในใบสมัครย้อนหลังที่ไม่มี snapshot จะยึดชื่อในทะเบียน **เมื่อเปิดพิมพ์ครั้งแรก** เพราะไม่มีประวัติชื่อจากใบสมัครเก่าที่บันทึกไว้ก่อนหน้านี้ หากโรงเรียนเคยเปลี่ยนผู้อำนวยการก่อนอัปเดต ควรตรวจชื่อก่อนพิมพ์ครั้งแรก
- หากไม่ระบุชื่อผู้อำนวยการหรือสนามของกีฬาที่ไม่มีค่าเริ่มต้น หน้า PDF จะแสดงคำเตือนและปิดปุ่มพิมพ์ฉบับสมบูรณ์
- การเปลี่ยนชื่อในข้อมูล **ส่งข้อมูลโรงเรียน/พิธีเปิด** ไม่ได้แก้ทะเบียนหลักอัตโนมัติ ให้แก้ชื่อสำหรับใบสมัครที่เมนู **โรงเรียน**
- อย่าแก้ค่าผู้อำนวยการในฐานข้อมูล `sports_entries.director_name_snapshot` โดยตรง เพราะเป็นหลักฐานย้อนหลัง
- ไม่ต้องเพิ่ม Environment Variables; ไม่ต้องลงทะเบียนนักกีฬาใหม่

## ตรวจสอบก่อนเปิดใช้งาน

- บัญชีโรงเรียน A แก้ชื่อผู้อำนวยการของ A ได้ แต่แก้ B ไม่ได้
- กรรมการที่มีสิทธิ์จัดการแข่งขันแก้โรงเรียนที่ร่วมการแข่งขันได้
- ใบสมัคร RoV เดิมและใบสมัครใหม่พิมพ์ PDF ได้ 2 หน้า A4 พร้อมรูปนักกีฬาเดิม
- ใบสมัครที่เคยพิมพ์ครั้งแรกแล้วมี snapshot จะใช้ชื่อเดิม แม้แก้ทะเบียนโรงเรียนภายหลัง
- กีฬาอื่นที่ตั้งค่า `sports_events.venue_name` แล้วแสดงสนามในใบสมัครได้

**การตรวจสอบในสภาพแวดล้อมนี้:** ตรวจ syntax TypeScript/TSX แล้ว และสร้างตัวอย่าง PDF A4 สองหน้าได้ แต่ไม่ได้รัน Production Build หรือเชื่อมต่อ Supabase จริง
