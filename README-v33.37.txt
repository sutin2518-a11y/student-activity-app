CKW v33.37 - Takraw Registration and Official Forms
ติดตั้งต่อจาก v33.36 โดยใช้ไฟล์เดียว ไม่ต้องวาง payload
1. หยุด npm run dev (Ctrl+C) และสำรอง/commit โค้ดเดิมบน branch แยก
2. คัดลอก apply-v33.37.cjs ไปยัง D:\ระบบ\student-activity-app (ข้าง package.json)
3. node apply-v33.37.cjs
   คาดว่า SUCCESS ... Files changed: 6 (ครั้งแรก) / 0 (รันซ้ำ)
   หาก STOP ห้ามฝืนเขียนทับ ให้ส่งข้อความ error
4. npm run build
5. สำรองฐานข้อมูล และทดสอบ SQL 202611250051_sports_takraw_official_forms_v33_37.sql ในฐานทดสอบก่อนใช้จริง
   SQL สร้างตารางข้อมูลนักกีฬาเฉพาะตะกร้อ + RPC 2 ตัว ไม่เปลี่ยน RPC กลาง/Storage policy เดิม
6. npm run dev แล้วเปิด http://localhost:3000/group-sports/takraw?tab=registration
7. ทดสอบทั้ง 4 รุ่น: สิทธิ์โรงเรียน, วันเกิด, เบอร์ 1-36, นักกีฬา 3-5 คน, เจ้าหน้าที่ 3 คน, Excel, รูป 8 ช่อง, แบบพิมพ์ 3 หน้า และการแก้ไขใบสมัครเดิม
8. นำ apply-v33.37.cjs ออกจาก root ก่อน commit; เก็บไฟล์ migration ใน supabase/migrations

รายละเอียด: รูปใน private bucket เดิม ผู้ใช้สามารถแนบหลังบันทึกซ้ำเมื่ออัปโหลดล้มเหลว ไม่ส่งใบสมัครซ้ำ; การรับสมัครไม่ใช่การยืนยันคุณสมบัติ รูปที่ยังไม่ครบมีข้อความเตือนก่อนพิมพ์ ต้องตรวจหลักฐานที่สนาม. วันเกิดเจ้าหน้าที่ไม่บังคับ (ต้นฉบับมีคอลัมน์วันที่ครอบคลุมแถวเจ้าหน้าที่). รุ่น 15 ปีเกิดตั้งแต่ 1 ม.ค. 2554. ไม่เพิ่มระดับชั้นหรือรหัสนักเรียนเป็นช่องกรอก. ใบสมัครหน้า 10 แก้ปี 2567 เป็น 2569. ใบส่งรายชื่อหน้า 11 ตำแหน่งและ C ใช้เฉพาะเอกสารครั้งนั้น ไม่บันทึกฐานข้อมูล. หากไม่พบคู่แข่งขันให้กรอกช่องว่างด้วยมือ. ชื่อ/สกุลในแผงรูปแบ่งจากช่องชื่อเต็มตามคำสุดท้าย ควรตรวจชื่อที่มีหลายคำ. แบบพิมพ์สร้าง HTML ตามโครงสร้างต้นฉบับ ไม่ใช่ภาพ PDF ต้นฉบับโดยตรง.
ข้อจำกัด: ยังไม่ได้ทดสอบ Next.js production build, PostgreSQL จริง, Storage upload, Excel ใน Microsoft Excel หรือ print A4 จริง. ทดสอบ syntax TS/TSX, 8 กรณีตรวจข้อมูลและวันที่, ติดตั้งซ้ำกับสำเนา v33.36 แล้ว. ไม่เปลี่ยน .env.local และไม่รีเซ็ตข้อมูล. การแก้ไขใบสมัครที่ได้รับอนุญาตสร้างแถวรายชื่อใหม่ตามกลไกเดิม; รูปผูกกับชื่อและลำดับ จึงอาจต้องแนบใหม่เมื่อแก้ชื่อ/ลำดับ. ใบสมัครเก่าที่ไม่มีข้อมูลวันเกิด/เบอร์จะขึ้นข้อความเตือน. ไม่ได้แก้ช่องทาง RPC กลางเก่าที่เรียกโดยตรง; ใช้หน้าเฉพาะกีฬานี้. SQL ต้องทดสอบสิทธิ์และ RLS ก่อนเปิดรับจริง. ไม่ควรนำขึ้น Production จนทดสอบและแก้ security warning Next.js แล้ว.
