# v30.2 — แก้ตาราง RoV ต่างกันระหว่าง Admin และผู้ชมทั่วไป

## สาเหตุ

RLS ใน Migration `202611210004_esports_management.sql` อนุญาตผู้ชมทั่วไปอ่าน `sports_esports_matches` เฉพาะ `match_status <> 'draft'` และรายการกีฬาต้องเผยแพร่แล้ว ดังนั้นบัญชี Admin เห็นคู่ร่างทั้งหมด แต่ผู้ชมทั่วไปเห็นเพียงคู่ที่เผยแพร่ ทำให้ตัวตรวจแผนสร้างข้อความ "ไม่พบคู่แข่งขัน" เพราะรายการคู่ถูกซ่อน

## สิ่งที่แก้

- เพิ่มปุ่ม **เผยแพร่โปรแกรมทีมชาย / ทีมหญิง** ในแท็บ **ตารางโปรแกรม** เฉพาะ Admin
- เมื่อกดปุ่มจะตรวจจำนวนคู่ (ทุกทีมพบกันหมด), ทีมคู่ซ้ำ, วันที่และเวลา แล้วขอให้ยืนยันก่อนเปลี่ยนเฉพาะคู่ `draft` ในรอบแบ่งกลุ่มเป็น `scheduled`
- ไม่แตะสถานะ `cancelled`, `completed`, รอบ Knockout, คะแนนหรือข้อมูลเวลาเดิม
- ผู้ชมทั่วไปที่ยังมีคู่ไม่เผยแพร่จะเห็นคำอธิบายว่า **โปรแกรมบางคู่ยังไม่เผยแพร่** แทนข้อความผิดพลาดเชิงเทคนิค
- ไม่แก้กฎ RLS และไม่เปิดสิทธิ์เขียนให้บัญชีทั่วไป

## วิธีใช้งาน

1. แตก Patch ทับโครงการ v30.1 แล้ว Commit → Push ผ่าน GitHub Desktop / Vercel
2. เข้าหน้า `/group-sports/esports` ด้วยบัญชีผู้ดูแลการแข่งขันจริง
3. เลือก **ทีมชาย → ตารางโปรแกรม** ตรวจวัน เวลาและคู่แข่งขัน กด **เผยแพร่โปรแกรมทีมชาย** และยืนยัน
4. ทำแบบเดียวกันกับ **ทีมหญิง** เมื่อกำหนดโปรแกรมเรียบร้อย
5. ทดสอบหน้าเดิมในโหมดไม่ระบุตัวตน (Incognito) กดรีเฟรช จะเห็นคู่ที่เผยแพร่โดยไม่จำเป็นต้องล็อกอิน

## การติดตั้งและข้อควรทราบ

- ไม่มี SQL Migration ใหม่ ใช้ RLS เดิมซึ่งปกป้องฉบับร่างอยู่
- หากกดแล้วแจ้งว่าข้อมูลไม่ครบ ให้ตรวจวัน เวลา หรือคู่แข่งก่อน ห้ามปลด RLS เพื่อแก้ปัญหานี้
- การเปลี่ยนสถานะเป็น `scheduled` หมายความว่า **เผยแพร่จริง** ไม่ควรกดจนกว่าคณะกรรมการจะยืนยันโปรแกรม
- ปุ่มนี้ใช้สิทธิ์ `sports_stage3_admin` และสิทธิ์ UPDATE ตาม RLS เดิม ผู้ใช้ทั่วไปไม่เห็นปุ่ม
- การตรวจโค้ดทำได้เฉพาะไวยากรณ์ TSX และไฟล์ ZIP ยังไม่ได้รัน Production Build หรือเชื่อมต่อ Supabase จริง
