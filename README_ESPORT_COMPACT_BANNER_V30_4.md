# E-Sport RoV — Compact Banner v30.4

## เปลี่ยนแปลง
- ลดความสูงแบนเนอร์เป็น 120 px บนเดสก์ท็อป, 110 px บนแท็บเล็ต และ 100 px บนมือถือ
- ใช้ไฟล์ภาพ RoV เดิม `/public/images/esports-rov-banner-2569.webp`
- แสดงภาพเป็นพื้นหลังตกแต่งเฉพาะด้านขวา พร้อมทำแถบสีทึบด้านซ้ายปิดตัวหนังสือในภาพเดิม และวางข้อความ HTML จริงให้อ่านง่าย ไม่ถูกครอป
- ลดระยะห่างของแถบนำทางและเนื้อหาหน้า E-Sport ให้เห็นสถิติ โปรแกรม และปุ่มเมนูเร็วขึ้น
- ไม่มีการแก้ไขฐานข้อมูล ข้อมูลกีฬา หรือกฎสิทธิ์

## ติดตั้ง Patch
1. สำรองไฟล์โครงการปัจจุบัน
2. แตก ZIP patch แล้วคัดลอก `src/app/group-sports/esports/page.tsx` ไปทับในโปรเจกต์ v30.3
3. Commit และ Push ผ่าน GitHub Desktop
4. ทดสอบบน Vercel Preview ทั้ง Desktop และ Mobile ก่อนนำขึ้น Production

ไม่ต้องรัน SQL เพิ่ม และไม่ต้องเปลี่ยน environment variables

## หมายเหตุการแสดงภาพ
ภาพ RoV ที่มีตัวหนังสือฝังอยู่ไม่สามารถย่อความสูง 1/3 พร้อมคงทุกข้อความในภาพเดิมให้ชัดได้ จึงใช้ภาพเดิมเป็นพื้นหลังตกแต่ง และแสดงชื่อการแข่งขันเป็นตัวอักษรจริงบนแถบสีกรมท่า ความคมชัดและการอ่านจะดีกว่าการย่อทั้งภาพเหลือ 120 px
