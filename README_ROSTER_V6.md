# ระบบกีฬากลุ่ม — เทมเพลต Excel มีดรอปดาวน์ (v6)

## สิ่งที่เปลี่ยน

1. **ทุกประเภทการแข่งขัน** — ในไฟล์เทมเพลตที่กดดาวน์โหลดจากเมนูลงทะเบียน คอลัมน์ C (`คำนำหน้าชื่อ`) มี Excel Data Validation แบบรายการเลือกจริง ครอบคลุมแถวกรอกนักกีฬาทุกแถว: `เด็กชาย`, `เด็กหญิง`, `นาย`, `นางสาว` เท่านั้น (ไม่มี `นาง`)
2. **RoV** — คอลัมน์ E (`บทบาทในทีม`) มีดรอปดาวน์ `หัวหน้าทีม`, `ตัวจริง`, `ตัวสำรอง`; คอลัมน์ G (`ตำแหน่งที่เล่น`) มีดรอปดาวน์ `Dark Slayer`, `Jungle`, `Midlane`, `Abyssal Dragon`, `Support`
3. หน้าเว็บลงทะเบียนทุกกีฬาก็ใช้ชุดคำนำหน้าเดียวกัน และเมนูตำแหน่ง RoV เปลี่ยน `Mid` เป็น `Midlane` ให้ตรงกับ Excel
4. รองรับอัปโหลดเทมเพลตรุ่นเก่าที่เคยใส่ `Mid` โดยแปลงให้เป็น `Midlane` ก่อนนำเข้าฟอร์ม
5. ข้อมูลประเภทชาย/หญิง/ผสมและรุ่นยังอยู่ที่ **รายการแข่งขัน** ไม่ได้เพิ่มช่องชั้นหรือเพศกลับเข้าฟอร์มนักกีฬา

## วิธีตรวจสอบใน Microsoft Excel

- อัปเดตโครงการ แล้วเปิด `กีฬากลุ่ม → ลงทะเบียน → เลือกรายการแข่งขัน → ดาวน์โหลดเทมเพลต Excel`
- เปิดด้วย Microsoft Excel แล้วคลิกเซลล์ `C2` จะมีลูกศรดรอปดาวน์ให้เลือกคำนำหน้าชื่อ
- สำหรับ RoV ทดสอบ `E2` (บทบาทในทีม) และ `G2` (ตำแหน่งที่เล่น); ทดลองเลือก `Midlane`
- ตรวจว่ารายการอื่น เช่น ฟุตบอล กรีฑา วอลเลย์บอล ก็มีดรอปดาวน์ที่คอลัมน์ `C` เช่นกัน
- กรอกชื่อจริงแล้วนำเข้าในรายการเดียวกันตามคู่มือ v5 ระบบยังตรวจสอบและแสดงรายชื่อให้ยืนยันก่อนบันทึก

## การอัปเดตจาก v5

1. สำรองโครงการเดิม จากนั้นแตก `student-activity-roster-v6-patch.zip` ที่ราก `student-activity-app/` โดยให้ไฟล์ใน `src/` ทับของเดิม
2. `npm ci` ตามวิธีติดตั้งเดิม แล้ว `npm run build`
3. Commit/Push และ Deploy; ล้างแคชหน้าเว็บหากยังเห็นตัวเลือกเดิม
4. ดาวน์โหลด **ไฟล์เทมเพลตใหม่หลัง Deploy** — เทมเพลตที่เคยดาวน์โหลดไว้ก่อนหน้าไม่สามารถเพิ่ม dropdown ย้อนหลังได้
5. **ไม่มี SQL Migration เพิ่ม** จาก v5

## ข้อจำกัด/ความเข้ากันได้

- ตัวสร้างไฟล์ปัจจุบันใช้ SheetJS Community Edition ซึ่งไม่รองรับการเขียน dropdown โดยตรง จึงเพิ่ม native Excel Data Validation เข้าไปในส่วน XML ภายใน ZIP (`xl/worksheets/sheet1.xml`) หลังสร้าง xlsx โดยไม่ใช้ dependency ใหม่
- ส่วนเพิ่ม dropdown รองรับไฟล์ ZIP แบบ Stored (`compression: false`) เท่านั้น และจะหยุดพร้อมข้อผิดพลาดชัดเจนหากโครงสร้างเปลี่ยน ไม่ดาวน์โหลดไฟล์ที่ไม่มี dropdown โดยไม่แจ้ง
- เทมเพลต `.xlsx` ที่สร้างใหม่มี dropdown; การอ่านไฟล์ยังรองรับ `.xlsx` และ `.xls` ตามเดิม
- บางโปรแกรมแสดงตัวเลือก Excel ต่างกัน เช่น Google Sheets/LibreOffice/Excel บนมือถือ ควรตรวจพฤติกรรมจริงด้วย Microsoft Excel ที่โรงเรียนใช้งาน
- การรันทดสอบในสภาพแวดล้อมนี้ตรวจความถูกต้อง ZIP/OOXML และการนำเข้า/แปลงค่าแล้ว แต่ยังไม่ได้รัน Next.js Production Build หรือทดสอบกับ Supabase จริง เพราะ node_modules ของไฟล์ต้นทางไม่มีไฟล์แพ็กเกจจริง
