# v23 — ภาพถ่ายนักกีฬาทุกประเภท (ฐานรองรับแบบฟอร์ม PDF เฉพาะกีฬา)

## สิ่งที่เพิ่ม
- แนบรูป JPG/PNG/WebP ของนักกีฬาทุกชนิดกีฬา ทั้งการลงทะเบียนใหม่และใบสมัครเดิม
- กีฬาทีม: แยกรูปแต่ละคนตามลำดับรายชื่อในใบสมัคร
- กีฬาเดี่ยว/คู่และกรีฑา: รองรับรูปแบบ 1 คน/ใบสมัคร และการนำเข้าหลายคนผ่าน Excel ซึ่งระบบแยกใบสมัครเป็นรายคน
- ใช้ Supabase Storage bucket `sports-athlete-photos` (private) เดิม จึงไม่ต้องย้ายรูป RoV หรือสมัครใหม่
- รูป RoV ยังคงถูกนำเข้าแบบพิมพ์สองหน้า 3–3–1 ตามที่ทำไว้
- เพิ่มตัวเลือกแม่แบบ PDF กลาง `sportsPrintTemplateFor()`; กีฬาอื่นใช้ใบสมัครทั่วไป **โดยยังไม่มีผังรูปอย่างเป็นทางการ** จนกว่าจะได้รับแบบฟอร์มจากคณะกรรมการกีฬาแต่ละชนิด

## ติดตั้ง
1. **สำรองฐานข้อมูลและไฟล์ที่เกี่ยวข้อง** ก่อนรัน SQL
2. ต้องรัน Migration 0016 และ 0017 เดิมให้เสร็จแล้ว
3. รัน `supabase/migrations/202611220018_all_sports_private_athlete_photos.sql` ใน Supabase SQL Editor
4. แตก Patch v23 ทับโครงการ **v22** โดยรักษาที่อยู่ไฟล์ภายใน `src/` และ `supabase/` ตามเดิม
5. Commit / Push แล้วทดสอบ Vercel Preview กับฐานข้อมูลทดสอบ ก่อนใช้งานจริง
6. ทดสอบโรงเรียนเจ้าของใบสมัคร: แนบรูปให้กีฬาเดี่ยวหนึ่งคน / ทีมหลายคน / RoV 7 คน และทดสอบว่าบัญชีโรงเรียนอื่นเปิดรูปไม่ได้

## วิธีใช้
- ลงทะเบียน: ในแต่ละแถวนักกีฬามีส่วน `รูปถ่ายนักกีฬา (ไม่บังคับ)` ให้เลือกภาพ ระบบอัปโหลดหลังบันทึกใบสมัครสำเร็จ
- ใบสมัครเดิม: เมนู `ลงทะเบียน` → เลือกใบสมัครเดิม → `แนบรูปใบสมัครเดิม` → เลือกภาพใต้ชื่อแต่ละคน
- ระบบใช้ชื่อและรหัสนักเรียนพร้อมลำดับรายชื่อเพื่อกำหนดรหัสไฟล์ จึงไม่แสดงรูปของคนเดิมเป็นรูปของคนอื่นเมื่อรายชื่อเปลี่ยน ทั้งนี้หากมีการแก้ชื่อ/รหัสหรือลำดับ ผู้ดูแลอาจต้องแนบรูปให้ตรงรายการอีกครั้ง
- ไม่มีไฟล์รูปในใบสมัคร PDF กีฬาอื่นจนกว่าจะเพิ่มแม่แบบเฉพาะกีฬา; รูปยังเก็บไว้ในระบบอย่างปลอดภัย
