CKW v33.30 — Boxing Management (ต่อจาก v33.29 / SQL 045)

ขอบเขต: ใช้รายการมวย GS3-BX เดิม 26 รายการ (13 รุ่น x ชาย/หญิง)
ไม่มีการสร้างนักกีฬา คู่ชก คะแนน หรือวันเวลาแต่ละคู่สมมติ ไม่เพิ่มโรงเรียนใหม่
PDF มีเฉพาะระเบียบและกำหนดการรวม ไม่มีสายจับฉลากจริง

ติดตั้ง:
1. สำรองโปรเจกต์และฐานข้อมูล หยุด npm run dev ด้วย Ctrl+C
2. ตรวจไฟล์ร่วมที่แก้เองหลัง v33.29 ก่อนคัดลอกไฟล์จาก ZIP ลงโปรเจกต์เดิม
3. รัน supabase/migrations/202611240046_sports_boxing_v33_30.sql ทั้งไฟล์ใน Supabase SQL Editor (ต้องผ่าน 045 แล้ว)
   หากพบข้อความว่ามีโปรแกรมมวยเดิม ให้ตรวจสอบก่อน ไม่ลบข้อมูลเอง
4. รัน diagnostics/202611240046_check_boxing.sql เพื่อตรวจจำนวนรายการ 26 และคู่ชก 0 ถ้ายังไม่ได้จับสาย
5. npm run build แล้ว npm run dev และเปิด http://localhost:3000/group-sports/boxing

การใช้งาน:
- โรงเรียนลงทะเบียนกลาง 1 นักกีฬาต่อใบสมัคร แยกเพศและรุ่นน้ำหนัก
- แม่แอดมินเปิดรับสมัคร/ปิดรับสมัคร ตรวจใบสมัครและผลชั่งน้ำหนักจริงจากเอกสารที่แพทย์และกรรมการลงนาม
- ระบบไม่ประเมินสุขภาพ ไม่แทนแพทย์ ไม่เก็บผลตรวจละเอียดหรือรูปเอกสารสุขภาพ เก็บเฉพาะน้ำหนักและสถานะรับรองในตารางปิด
- กรรมการได้รับมอบหมายเฉพาะรายการผ่านระบบเดิม เห็นเฉพาะรายชื่อและสถานะรับรอง ไม่เห็นน้ำหนักจริง
- เลือกลำดับนักกีฬาที่ผ่านตรวจตามผลจับฉลากจริง (2–64 คน) เพื่อสร้างสายแบบแพ้คัดออกและ BYE
  วิธีจับคู่: สร้างขนาดสายเป็นกำลังของ 2; คู่แรกช่อง 1 กับช่องครึ่งหลังที่ตรงกัน; ช่องว่างเป็น BYE
  ตรวจผังจริงก่อนเผยแพร่ หากต้องแก้ลำดับ ใช้ล้างสายฉบับร่าง (เฉพาะรุ่นนี้; ไม่ลบใบสมัครหรือผลตรวจ)
- กำหนดวัน/เวลาเริ่มและสิ้นสุดทุกคู่ ตรวจเวลาชนข้ามรุ่นและลำดับคู่ก่อน–หลัง
- กำหนดเวทีเดียวเป็นค่าเริ่มต้นตามสถานที่ใน PDF (หากมีหลายเวทีต้องปรับเพิ่ม)
- กรรมการบันทึกผู้ชนะ วิธีตัดสิน และยกที่จบจากใบผลจริง ไม่สร้างคะแนนสมมติ
- หลังครบคู่ เสนออันดับตามผลจริง; ผู้จัดต้องยืนยันกติกาอันดับก่อนสร้างสาย
- ประกาศอันดับผ่าน sports_cert_submit เดิม (ต้องเป็นกรรมการที่มีสิทธิ์บันทึกอันดับ รวมถึงแม่แอดมินถ้าจะประกาศเอง)
- เชื่อมหน้าโปรแกรมส่วนกลางและหน้าหลักด้วย public RPC ที่คืนเฉพาะโรงเรียน ไม่คืนชื่อนักกีฬา/น้ำหนัก/ผลตรวจ
  หน้าเฉพาะมวยโหลดใหม่เป็นรอบทุก 30 วินาที หน้าแรกตาม polling เดิม ไม่ใช่ Realtime push ทันที

ข้อสังเกต/สิ่งที่ต้องยืนยัน:
- PDF หน้า 2 ระบุวันพุธที่ 3 ธ.ค. 2569 แต่วันตามปฏิทินเป็นวันพฤหัสบดี; ใช้วันที่เป็นหลักและให้ผู้จัดยืนยัน
- พิธีเปิดระบุ 6 ธ.ค. 13:00 ไม่เปลี่ยนเอง
- PDF ไม่ชัดเจนเรื่องอันดับรองและเกณฑ์ถ้วยรวม จึงเสนอผู้ชนะรอบชิงอันดับ 1 ผู้แพ้รอบชิงอันดับ 2 ผู้แพ้รอบรองที่แข่งจริงอันดับ 3 ร่วม
- รุ่น 2 คน: 2 อันดับ; 3 คน: 3 อันดับ; >=4 คน: 4 อันดับ ตามข้อเสนอที่ผู้จัดต้องยืนยัน; 0–1 คนยังไม่ออกอันดับอัตโนมัติ
- ถ้วยรวมชาย/หญิง และนักชกยอดเยี่ยม ยังไม่อัตโนมัติ
- หากมีสองคนจากโรงเรียนเดียวกันได้อันดับเดียวกัน ระบบหยุดเสนอรางวัลเพราะตารางเหรียญเดิมอาจรวมเหรียญซ้ำ
- วันรอบคัดเลือกใช้ 3–4 ธ.ค. (วันที่ 4 ไม่ระบุใน PDF ต้องยืนยันกับผู้จัด); รอบรอง 5 ธ.ค.; รอบชิง 6 ธ.ค.
- การแก้ไขผลหลังประกาศ และการล้างผลมวยจริง/ศูนย์ TEST ยังไม่รองรับ ห้ามใช้ reset เดิมโดยคาดว่าจะลบตารางมวยใหม่ครบ
- การตรวจเพศ อายุ หลักฐาน การชั่งซ้ำ/ถอนตัว/กรณีคำตัดสินพิเศษต้องดำเนินการโดยเจ้าหน้าที่ ไม่มีระบบวินิจฉัยแพทย์หรือคำนวณคะแนนจากกรรมการแต่ละคน
- การนำเข้า Excel และ Admin Full Control ต้องทดสอบร่วมกับมวย; ระบบตรวจ snapshot ใบสมัครเมื่อบันทึกผล/ประกาศเพื่อหยุดหากข้อมูลไม่ตรงกับตอนตรวจ
- ไม่ลบข้อมูลเดิมอัตโนมัติ แต่ migration มีการแทนที่ RPC ร่วมจาก 045 และ RPC แก้ไขผลจาก 041 เพื่อเพิ่มเงื่อนไขมวยเท่านั้น ให้สำรองก่อน
