# ระบบมอบหมายกรรมการและบันทึกผลการแข่งขัน v33.7.1

## วิธีเข้าใช้งานของกรรมการ

1. ผู้ดูแลหลักเปิด `/group-sports/officials` แล้วเลือกรายการแข่งขัน/รุ่นที่ต้องการ
2. กรอกอีเมล Google ของกรรมการ แล้วกดเพิ่มผู้รับผิดชอบรายการนี้
3. หากกรรมการคนเดียวดูแลหลายรายการ ให้เพิ่มอีเมลเดิมซ้ำในแต่ละรายการที่รับผิดชอบ
4. กรรมการเปิด `/login` แล้วเลือก **เข้าสู่ระบบด้วย Google Workspace** โดยเลือกบัญชี Google ที่ตรงกับอีเมลที่ Admin มอบหมาย
5. เมื่อยืนยันตัวตนสำเร็จ ระบบจะพาไป `/group-sports/results` และแสดงเฉพาะรายการที่อีเมลนั้นได้รับมอบหมาย
6. เลือกรายการ บันทึกอันดับ แล้วส่งให้ Admin ตรวจสอบ

**อย่าใช้ `/group-sports/login` สำหรับกรรมการ** เพราะ URL นั้นเป็นล็อกอิน Username/Password ของโรงเรียนที่เข้าร่วมการแข่งขันเท่านั้น

## สิ่งที่แก้เพิ่มใน v33.7.1

- แก้ `src/app/auth/complete/page.tsx` ให้ตรวจสิทธิ์กรรมการจาก `sports_cert_context()` หลังยืนยัน Google แล้ว
- กรรมการที่ Admin มอบหมายอีเมลไว้จึงเข้าได้ แม้เป็นบัญชี Google ภายนอก `@chiangkham.ac.th` โดยไม่ต้องเพิ่ม role กว้างใน `sports_user_roles`
- เมื่อตรวจพบว่าเป็นกรรมการที่ได้รับมอบหมาย ระบบจะพาไปหน้าบันทึกผลโดยตรง
- ยังคงตรวจบัญชี Google ที่ยืนยันอีเมลแล้ว และ backend RPC ตรวจสิทธิ์ซ้ำทุกครั้ง

## URL สำคัญ

- `/login` — ล็อกอิน Google Workspace สำหรับ Admin/กรรมการ
- `/group-sports/results` — กรรมการบันทึกผล
- `/group-sports/officials` — Admin มอบหมาย/ระงับกรรมการรายรายการ
- `/group-sports/results/review` — Admin ตรวจ อนุมัติ ส่งกลับแก้ไข และเผยแพร่ผล
- `/group-sports/certificates` — โรงเรียนพิมพ์เกียรติบัตรด้วยบัญชีโรงเรียนเดิม
- `/group-sports/login` — ล็อกอิน Username/Password ของโรงเรียนเท่านั้น

## การติดตั้ง

1. สำรอง/Commit โปรเจกต์ปัจจุบันก่อน
2. แตก ZIP นี้และวางทับตาม path โดยใช้ไฟล์ทั้งชุดใน ZIP (รวม v33.7 และ auth fix)
3. ไม่ต้องรัน SQL ใหม่ หากติดตั้ง migration `202611230027_sports_certificates_v1.sql` แล้ว
4. รัน `npm run build`
5. Commit + Push และทดสอบด้วยบัญชี Admin, กรรมการ CKW และกรรมการ Google ภายนอกที่ได้รับมอบหมาย

## ขอบเขต

- กรรมการเห็นและบันทึกได้เฉพาะ event ที่อีเมลตนได้รับมอบหมายและยัง active
- กรรมการไม่มีสิทธิ์มอบหมายคนอื่น อนุมัติ หรือเผยแพร่ผล
- Admin เป็นผู้ตรวจ อนุมัติ/ส่งกลับแก้ไข และเผยแพร่
- ระบบนี้ส่งอันดับผู้ชนะเพื่อออกเกียรติบัตร ไม่ใช่หน้าบันทึกสกอร์แมตช์ฟุตบอลหรือ RoV ซึ่งยังใช้หน้ากีฬาเฉพาะเดิม
