# PHAYAO GAMES — v33.12: เมนูหลักเดิม แบบข้อความล้วน

## สรุปการเปลี่ยนแปลง

**ใช้เมนูหลักและฟังก์ชันเดิมของระบบทั้งหมด** ไม่ได้สร้างเมนูสาธารณะชุดใหม่ตามภาพอ้างอิง โดยย้ายเมนูหลักจากแถบการ์ดไอคอนใต้แบนเนอร์ไปไว้บนแถบน้ำเงินเข้มแทนเมนูตัวอักษร 7 รายการของ v33.11

เมนูหลักยังเรียงตามต้นฉบับ: **หน้าหลัก / ข้อมูลทั่วไป / จัดการแข่งขัน / โรงเรียน / ลงทะเบียน / ตารางคะแนน / เหรียญรางวัล / บัญชีโรงเรียน** (บัญชีโรงเรียนแสดงเฉพาะผู้มีสิทธิ์ดูแลบัญชี)

- เปลี่ยนเมนูหลักเป็น **ข้อความล้วน ไม่มีไอคอน**; แสดงข้อความสีขาวบนพื้นน้ำเงินเข้มและขีดเส้นเหลืองใต้เมนูที่กำลังใช้งาน
- รักษาการกดสลับแท็บ การเปิด/ปิด Dropdown ข้อมูลทั่วไปและจัดการแข่งขัน, ค่า state, การเลื่อนไปยังหน้าเดิม และคำสั่งทุกปุ่ม
- เมนูย่อยของสองหมวดแสดงเป็น **รายการข้อความล้วน** และยังเชื่อมหน้าเดิม เช่น เกียรติบัตร, ผลแข่งขัน, กรรมการ
- **ลบแถบการ์ดไอคอนด้านล่างออกจากตำแหน่งเดิม** ไม่ได้ซ่อนเฉพาะหน้าแรก; มีแถบเมนูหลักชุดเดียว
- คง **เมนูระบบ** ทางขวาเฉพาะ Admin, กรรมการ หรือโรงเรียนที่เข้าสู่ระบบและได้รับสิทธิ์; ผู้เข้าชมทั่วไปจะเห็น "เข้าสู่ระบบ"
- ห้ามเพิ่มสิทธิ์ผู้ใช้ด้วยการแสดงปุ่ม; RPC/RLS ของ Supabase ยังเป็นผู้บังคับใช้สิทธิ์เดิม
- หน้าจอแคบใช้แถบข้อความเลื่อนแนวนอน โดยไม่เปลี่ยนโครงสร้างเมนู

## ไฟล์ที่แก้ไข

1. `src/components/group-sports/GroupSportsDashboard.tsx` — ย้าย **เมนูเดิมจริงทั้งชุด** ขึ้นแถบหัว และถอดไอคอนออกจากการแสดงผล
2. `src/app/group-sports/sports-games-theme.css` — ข้อความขาว/เหลืองบนแถบกรมท่า ปรับขนาด Desktop และ Mobile
3. `tests/group-sports-menu-v33-12.test.mjs` — ตรวจว่าชุดเมนูและสิทธิ์คงอยู่ ไม่มีเมนูซ้ำ

## ติดตั้ง

1. Commit และ Pull โค้ดล่าสุดใน GitHub Desktop ก่อน เพื่อรักษางานทั้งเครื่องบ้านและโรงเรียน
2. แตก ZIP เต็ม **เป็นโฟลเดอร์แยกก่อน** ตรวจเปรียบเทียบกับโค้ดบน GitHub ก่อนวางทับ เพราะ ZIP สร้างจากฐาน v33.11 ที่มีอยู่ในบทสนทนา
3. หากโค้ดล่าสุดบน GitHub ใหม่กว่า ให้คัดลอกเฉพาะ 2 ไฟล์โค้ดข้างต้นและไฟล์ทดสอบ แทนการวางทับทั้งโฟลเดอร์
4. **ไม่ต้องรัน SQL ใหม่** เนื่องจากเป็นงานหน้าเว็บอย่างเดียว
5. เปิด VS Code รัน `npm run build` จากเครื่องที่ติดตั้ง dependencies แล้ว ตามด้วย Commit และ Push
6. ทดสอบแท็บทุกตัว เมนูย่อยทั้งสอง ผู้ชมทั่วไป กรรมการ Admin และบัญชีโรงเรียน; ทดสอบในจอมือถือด้วย

## สถานะการตรวจ

- ตรวจ parse TS/TSX ออฟไลน์ด้วย TypeScript; ทดสอบโครงสร้างเมนูและเมนูระบบด้วย Node.js
- ตรวจ layout ด้วย Chromium แบบ static เพื่อดูความกว้าง ขนาดตัวอักษร และการเลื่อนในจอเล็ก
- **ยังไม่ได้ยืนยัน Next.js Production Build หรือทดสอบการล็อกอินจริงกับ Supabase**

ไฟล์ ZIP ไม่รวม `public.zip` ซึ่งเป็นไฟล์สำรองที่เคยติดค้าง แต่ยังคงโฟลเดอร์ `public/` จริงครบ
