# ระบบกีฬากลุ่ม ภูลังกาเกมส์ 2569 — หน้าแรกและธีมใหม่ v33.11

**ฐานโค้ด:** โปรเจกต์ v33.10 Admin Full Control ที่ผู้ใช้ได้รับก่อนหน้า ไม่ใช่การสร้างโปรเจกต์ใหม่

## สิ่งที่เปลี่ยน

1. `/group-sports` ใช้แถบเมนูน้ำเงินเข้ม โลโก้และแบนเนอร์ที่ตัดจากภาพต้นแบบที่ผู้ใช้ส่ง (ใน `public/images/group-sports/`) เพื่อคงภาพ สี และสัดส่วน Desktop ใกล้ต้นฉบับ
2. หน้าแรกแสดงแผงสถิติ 4 รายการ การแข่งขันล่าสุด/โปรแกรม ผลการแข่งขัน ตารางเหรียญแนวตั้งทั้งหมด และข่าวประกาศ
3. ตัวเลข/ผล/เหรียญอ่านจากฐานข้อมูลจริง ไม่ใส่ตัวเลข 18, 96, 1,240 หรือผล 2:1 แบบภาพต้นแบบลงระบบจริง
4. ตารางเหรียญมี dropdown เลือกประเภทกีฬา และเรียงตามจำนวนเหรียญทอง → เงิน → ทองแดง
5. โปรแกรมและผลดึงข้อมูลจาก `sports_matches` + ตารางเฉพาะ `sports_football_matches` และ `sports_esports_matches` เฉพาะคู่ที่เปิดเผยต่อผู้ชม; ลิงก์จากคู่ฟุตบอล/RoV เปิดระบบกีฬาเฉพาะ
6. ประกาศดึงข้อมูลที่ `is_published=true` จาก `sports_school_information` (section `announcements`)
7. รองรับหน้าจอ Desktop/Tablet/Mobile: mobile เปลี่ยนจากภาพแบนเนอร์ตัวอักษรฝังเป็นข้อความ HTML จริงเพื่อให้อ่านง่าย
8. ใช้ theme ใหม่ทั้ง `/group-sports/*` สี navy / royal blue / cyan / neon yellow พร้อมสถานะสีเขียว ม่วง ส้ม; action อันตราย/แจ้งเตือนสำคัญยังคงสีแดงแยกจากปุ่มทั่วไป
9. เมนูเดิมที่เป็นระบบจัดการยังอยู่ครบในเมนูระบบเพิ่มเติม (☰) และแถบเมนู 8 ช่องเมื่อเปิดหน้าภายใน
10. ตั้ง Supabase Realtime สำหรับผลแข่งและประกาศ พร้อม polling fallback 45 วินาที โดยไม่ทำให้หน้า dashboard กระพริบในระหว่างอัปเดต

## ติดตั้ง

1. สำรอง Git Commit ที่ใช้งานล่าสุดบนคอมพิวเตอร์และ Supabase ก่อน
2. แตก ZIP **ในโฟลเดอร์ใหม่** แล้วเปรียบเทียบกับโค้ดบน GitHub ที่ล่าสุด ก่อนคัดลอก/merge เพื่อป้องกันทับ commit จากอีกเครื่อง
3. ไป Supabase SQL Editor รัน `202611230034_sports_public_overview_counts_v33_11.sql` หลัง migrations 0001–0033 ครบแล้ว เพื่อให้ทุกคนเห็นจำนวนนักกีฬารวมโดยไม่เห็นข้อมูลส่วนบุคคล หากยังไม่รัน ช่องนักกีฬาเป็น `—` ในบัญชีที่ไม่เห็น roster (ไม่แสดงตัวเลขเดา)
4. ในโฟลเดอร์โปรเจกต์ที่มี `node_modules` ครบ รัน `npm run build`
5. ตรวจหน้า `/group-sports` ทั้งหน้าคอมและมือถือ, ทดสอบตัวกรองเหรียญ, ลิงก์คู่กีฬา, ข่าว และแถบเมนูเพิ่มเติม
6. หาก Build ผ่าน Commit + Push ขึ้น GitHub แล้วตรวจ Vercel Production/Preview

## ความถูกต้องของข้อมูล

- ไม่แสดงผลตัวอย่างของภาพอ้างอิงใน Production ยกเว้นโหมดสาธิตของโปรเจกต์เดิมในกรณีไม่ติดตั้งระบบฐานข้อมูล
- ฟุตบอล/RoV จะปรากฏเฉพาะรายการและคู่ที่ผ่าน RLS การเผยแพร่แล้ว จึงอาจยังไม่แสดงในหน้าแรกจนกว่าจะเผยแพร่โปรแกรมจริง
- สถานะ LIVE จะปรากฏเฉพาะข้อมูลแมตช์ที่มีสถานะ `live`/`in_progress` ในฐานระบบกลาง การมีเวลานัดหมายตรงปัจจุบันเพียงอย่างเดียวไม่เพียงพอที่จะบอกว่ากำลังแข่งขัน
- ภาพแบนเนอร์ตัวอักษรฝังเป็น raster ที่ตัดจากรูปต้นฉบับ ความคมชัดสูงสุดขึ้นกับภาพที่ส่งมา ไม่สามารถรับประกันว่า “100%” ในทุกขนาดหน้าจอ ขณะที่การ์ด ตาราง และปุ่มเป็น HTML จริงที่ปรับได้
- หาก Realtime publication ของ Supabase ไม่เปิดสำหรับตารางบางตัว ระบบจะดึงข้อมูลใหม่ทุก 45 วินาทีแทน
