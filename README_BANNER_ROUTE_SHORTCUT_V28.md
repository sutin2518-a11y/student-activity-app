# v28 — ปุ่มเลือกเส้นทางพาเหรดบนแบนเนอร์

ต่อยอดจาก **v27** โดยใช้ปุ่ม “แผนที่และการนำทาง” สีขาวที่ **มุมขวาล่างของแบนเนอร์** เปิดรายการเพียง 2 เส้นทาง ไม่พาผู้ใช้ไปหน้าเว็บอีกชั้น

1. **เส้นทางที่ 1 — อำเภอจุน → จุดท้ายขบวนพาเหรด:** เริ่มต้นด้วยพิกัดที่ผู้จัดส่งให้ (จุดผ่าน 19.5194041,100.3013921 และ 19.524234,100.3003952; ปลายทาง 19.530361,100.295979) ปุ่มเปิด Google Maps โดยตรง
2. **เส้นทางที่ 2 — อำเภอปง → จุดหัวขบวนพาเหรด:** แสดงเป็นรายการอยู่แล้ว แต่มีป้าย “รอเพิ่มลิงก์” และไม่ให้กดนำทางจนกว่าผู้ดูแลจะใส่ลิงก์

## Admin เพิ่มลิงก์ภายหลัง

เข้าสู่ระบบด้วยบัญชี `competition_admin` / `super_admin` ของรายการกีฬากลุ่ม จากนั้นกด **แผนที่และการนำทาง** บนแบนเนอร์ → **เพิ่มลิงก์ Google Maps** ใต้เส้นทางที่ 2 → วาง URL → **บันทึกลิงก์**. ระบบจะบันทึกลง `sports_parade_routes` และทุกโรงเรียนเห็นลิงก์หลังเปิดหน้าใหม่/รีเฟรช (ไม่ต้อง deploy/แก้โค้ดอีก)

แก้ไขเส้นทางที่ 1 ได้ด้วยปุ่มเดียวกัน. รับ URL จาก `google.com/maps`, `google.co.th/maps`, `maps.google.com`, `maps.app.goo.gl` หรือ `goo.gl/maps` ที่เป็น HTTPS เท่านั้น (สูงสุด 2048 ตัวอักษร). หากแก้/ลบลิงก์ที่ 2 เป็นค่าว่าง ระบบจะกลับเป็นสถานะรอเพิ่มลิงก์

เมนู **ข้อมูลสำหรับโรงเรียน → แผนที่และการนำทาง** จาก v27 ยังคงอยู่สำหรับประกาศเอกสาร/จุดหมายอื่น ๆ; ปุ่มบนแบนเนอร์เป็นทางลัดพิเศษที่แสดงแค่สองเส้นทาง และมีข้อมูลแยกในตาราง `sports_parade_routes`

## ติดตั้งจาก v27

1. สำรองฐานข้อมูล Supabase
2. ไปที่ Supabase SQL Editor แล้วรัน `supabase/migrations/202611220023_sports_banner_parade_routes.sql` **หลัง 0021 และ 0022**
3. แตก Patch v28 ทับโครงการ v27 โดยรักษาโครงสร้าง path:
   - `src/components/group-sports/GroupSportsDashboard.tsx` (แก้ไข)
   - `src/components/group-sports/ParadeRouteShortcut.tsx` (ไฟล์ใหม่)
   - `supabase/migrations/202611220023_sports_banner_parade_routes.sql` (ไฟล์ใหม่)
4. Commit / Push ด้วย GitHub Desktop → ทดสอบ Vercel Preview → Production
5. ทดสอบสิทธิ์: หน้าเว็บโรงเรียนกดเส้นทางที่ 1 ได้, เส้นทางที่ 2 เปิดไม่ได้ก่อนมีลิงก์, Admin กรอกเส้นทางที่ 2 แล้วใช้งานได้จริง

**หมายเหตุด้านการเดินทาง:** Google Maps อาจคำนวณเส้นทางใหม่ตามการจราจร/ข้อจำกัดถนน แม้ใส่ Waypoints แล้ว; ตรวจสอบแนวเส้นทางก่อนเผยแพร่ให้โรงเรียน และเจ้าหน้าที่หน้างานต้องยืนยันทางเข้าจริง
