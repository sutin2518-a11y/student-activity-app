# กีฬากลุ่ม v33.14 — ปรับหน้าลงทะเบียนให้ใช้ร่วมกันทุกกีฬา

ต่อยอดจาก v33.13 โดยแก้เฉพาะส่วน UI ของ `src/components/group-sports/GroupSportsDashboard.tsx`

## รายการแก้ไข
- ลบกล่องประกาศพื้นหลังสีเหลืองที่ระบุ `หากลงทะเบียน RoV ไว้แล้ว ไม่ต้องสร้างใบสมัครใหม่` ออกจาก **ฟอร์มลงทะเบียนทีม / นักกีฬา**
- ลบปุ่ม `ไปที่ใบสมัครเดิม ↓` ที่อยู่ในกล่องประกาศนั้น
- ไม่ลบเมนู/ส่วนรายชื่อใบสมัครเดิมที่อยู่ด้านล่าง และคง `ดูรายชื่อ`, `แนบรูปใบสมัครเดิม`, `พิมพ์ใบสมัคร PDF`, สิทธิ์ Admin และการลงทะเบียนเดิมไว้ทั้งหมด
- ไม่มีการเปลี่ยนฐานข้อมูลหรือคำสั่ง Supabase, ไม่ต้องรัน SQL ใหม่

## ขั้นตอนติดตั้ง
1. สำรองงานและ Commit ก่อน
2. ใช้ ZIP เต็มโดยแตกลงโฟลเดอร์ใหม่เพื่อเปรียบเทียบกับโปรเจกต์ปัจจุบัน โดยเฉพาะถ้ามี Commit จากเครื่องโรงเรียน/บ้านที่ใหม่กว่า v33.13
3. ย้ายเฉพาะไฟล์แก้ไขเข้าโปรเจกต์ที่ใช้งานจริง หรือใช้ ZIP แพตช์
4. รัน `npm run build` บนเครื่องที่มี dependencies
5. Commit และ Push ขึ้น GitHub จากนั้นทดสอบหน้าลงทะเบียน

## การตรวจสอบ
- เปิดเมนู `ลงทะเบียน` แล้วกด `＋ ลงทะเบียนรายการใหม่` ไม่ควรเห็นข้อความแนะนำเฉพาะ RoV หรือปุ่มเลื่อนไปใบสมัครเดิม
- เลือกรายการแข่งขันทั่วไปหรือ RoV ได้ตามข้อมูล/สิทธิ์เดิม
- รายชื่อใบสมัครด้านล่างยังมีปุ่ม `ดูรายชื่อ` และ `แนบรูปใบสมัครเดิม` ที่ทำงานตามเดิม

## ขอบเขตการทดสอบ
ตรวจ TypeScript syntax และตรวจการคงไว้ของ JSX/Fn ที่เกี่ยวข้องได้แบบออฟไลน์ ยังไม่ได้ทดสอบ Production Build กับ Supabase จริง
