# v29 — รวมภาพลำดับขบวน ผังพิธีเปิด และสถานที่ตั้งขบวน ภูลังกาเกมส์ 2569

ต่อจาก **v28** (รวมการเพิ่มภาพสถานที่ตั้งขบวนในชุด v29 นี้แล้ว ไม่ต้องติดตั้ง v29 ฉบับเก่าก่อน) โดยนำภาพต้นฉบับที่ผู้จัดการแข่งขันให้มา **3 ภาพ** ใส่ในเมนู **ข้อมูลสำหรับโรงเรียน** โดยตรง ไม่ต้องให้ Admin อัปโหลดซ้ำ และไม่ต้องเพิ่ม SQL

## ภาพและเมนูที่แสดง

1. **ข้อมูลสำหรับโรงเรียน → ลำดับขบวน**
   - ใช้ภาพ `public/images/group-sports/parade-order-2569.png` — รายชื่อขบวนโรงเรียนลำดับ 1–20 ตามไฟล์ที่ได้รับ
2. **ข้อมูลสำหรับโรงเรียน → แผนผังการยืนขบวนในสนาม**
   - ใช้ภาพ `public/images/group-sports/opening-ceremony-and-cheer-stands-2569.png` แสดงผังสนาม ลู่วิ่ง จุดยืน และอัฒจันทร์
3. **ข้อมูลสำหรับโรงเรียน → อัฒจันทร์กองเชียร์**
   - ใช้ภาพต้นฉบับ **ภาพเดียวกันกับข้อ 2** เนื่องจากมีผังจัดสแตนเชียร์ในแถบด้านบนอยู่แล้ว ไม่เก็บสำเนาภาพซ้ำ
4. **ข้อมูลสำหรับโรงเรียน → จุดตั้งขบวน**
   - ใช้ภาพ `public/images/group-sports/parade-assembly-location-2569.png` แสดงภาพถ่ายแผนที่บริเวณถนนหมายเลข 1148 พร้อมจุดสีเหลืองและเส้นระยะทางตามภาพที่ได้รับ
   - แสดงพรีวิว `parade-assembly-location-2569-preview.webp` และให้กดขยาย ซูม หรือดาวน์โหลดภาพจริงได้
   - **หมายเหตุ:** เป็นภาพผังพื้นที่ตั้งขบวน ไม่ใช่แผนที่นำทาง Google Maps ทั้งสองเส้นทางบนแบนเนอร์ยังทำงานเหมือน v28

โรงเรียนกดดูภาพขนาดใหญ่ได้ทันที พร้อมปุ่มซูม +/− ปุ่มเปิดภาพต้นฉบับ และดาวน์โหลดภาพจริง ภาพต้นฉบับ PNG เก็บความละเอียดเต็ม (1024×1536, 1495×1052 และ 1452×821) และใช้ WebP ขนาดเล็กเพื่อแสดงพรีวิวให้หน้าเว็บโหลดเร็วขึ้น

หากคณะกรรมการอัปเดตผังในภายหลัง Admin สามารถใช้ระบบประกาศเดิม (Migration 0021) อัปโหลดภาพและกดเผยแพร่ในหัวข้อนั้น เมื่อมีภาพใหม่ที่เผยแพร่แล้ว **ภาพต้นฉบับที่ฝังกับ v29 จะไม่แสดงซ้ำในหัวข้อนั้น** เพื่อป้องกันการเห็นผังสองฉบับพร้อมกัน การแก้ผังในเมนูสนาม/สแตนเชียร์ซึ่งใช้ภาพร่วมกัน ควรเผยแพร่ภาพฉบับใหม่ในทั้งสองหมวดด้วย

**ข้อควรตรวจสอบก่อนวันงาน:** ภาพลำดับขบวนต้นฉบับมี 20 โรงเรียน (ลำดับที่ 1–20) ขณะที่ฐานข้อมูลโรงเรียนที่เข้าร่วมการแข่งขันอาจมีมากกว่านั้น การแสดงภาพนี้ไม่ปรับจำนวนโรงเรียนและไม่ผูกลำดับขบวนกับบัญชีโรงเรียนอัตโนมัติ โปรดให้คณะกรรมการยืนยันรายชื่อและตำแหน่งในผังก่อนใช้จัดแถวจริง
