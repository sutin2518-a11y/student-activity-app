# v27 — Google Maps navigation in School Information

เริ่มจากโครงการ v26.2; ต้องรัน migration 202611220022 **หลัง 0021**

## การใช้งานผู้ดูแล
1. เปิด “ข้อมูลสำหรับโรงเรียน” → “แผนที่และการนำทาง”
2. กด “+ เพิ่มจุดหมาย” ใส่ชื่อจุดหมาย รายละเอียดและ **ลิงก์ Google Maps**
3. ใน Google Maps เลือกสถานที่ → “เส้นทาง” → “แชร์” → คัดลอกลิงก์เส้นทาง ถ้าต้องการให้เปิดหน้าเส้นทางโดยตรง
4. บันทึกฉบับร่าง ตรวจสอบลิงก์ แล้วกด “เผยแพร่ให้โรงเรียนเห็น”
5. เพิ่มหลายจุดหมายได้ เช่น จุดรวมพลขบวน, จุดส่งขบวน, อัฒจันทร์, สนามแข่ง, ที่จอดรถ

โรงเรียนกด “นำทาง Google Maps” เพื่อเปิดแผนที่ในแท็บ/แอป Google Maps และนำทางจากตำแหน่งปัจจุบัน (ถ้าอนุญาตสิทธิ์ที่ Google Maps)

## รายการอื่นก็ใส่ลิงก์ได้
หมวด “จุดตั้งขบวน”, “แผนผังการยืนขบวน”, “อัฒจันทร์กองเชียร์”, “ลำดับขบวน”, “ประกาศและเอกสารอื่น ๆ” มีช่องลิงก์ Google Maps เพิ่ม โดยไม่บังคับกรอก

## ความปลอดภัย
- รองรับเฉพาะ HTTPS Google Maps/official shortened share links; ตรวจสอบซ้ำก่อนแสดง
- ข้อมูลไม่ได้เผยแพร่จนผู้ดูแลกดยืนยัน; โรงเรียนเห็นเฉพาะข้อมูลที่เผยแพร่
- ลิงก์เป็นลิงก์ภายนอก ไม่ส่งที่ตั้งโรงเรียนหรือผู้ใช้ไปยังระบบของเรา
- ตรวจจุดหมายก่อนเผยแพร่ โดยเฉพาะพิกัดซุ้มจอดรถหรือจุดรวมพล; แผนที่เก่าปี 2567 ไม่ใช่แผนปี 2569 ที่ยืนยันแล้ว

## ติดตั้ง
1. สำรองฐานข้อมูล Supabase
2. Run `supabase/migrations/202611220022_sports_school_google_maps_navigation.sql`
3. แตก Patch ทับ v26.2 รักษาโครงสร้างโฟลเดอร์
4. Commit / Push ผ่าน GitHub Desktop แล้วทดสอบ Vercel Preview บนฐานทดสอบก่อน Production
5. ทดสอบเปิดลิงก์ Maps ทั้งคอมและมือถือ และการตั้งสถานะร่าง/เผยแพร่/ถอนเผยแพร่

ไม่ต้องเพิ่ม Environment Variables หรือ Google Maps API Key
