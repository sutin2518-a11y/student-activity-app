# ระบบกีฬากลุ่ม v33.4 — ลบใบสมัครรายรายการและรีเซตข้อมูลทดลองก่อนแข่งขัน

**สถานะ:** เพิ่มโค้ดและ SQL เพื่อให้ผู้ดูแลติดตั้ง/ทดสอบเท่านั้น ยังไม่มีการลบข้อมูลบน Supabase จริง และยังไม่ได้ยืนยัน `npm run build` ในสภาพแวดล้อม Production

## สิ่งที่เพิ่ม

- หน้า `/group-sports/reset` สำหรับ **Admin หลัก** ที่มีสิทธิ์ `sports_stage3_admin` ของงานกีฬากลุ่ม 2569 เท่านั้น
- บนหน้า **ลงทะเบียน** Admin จะเห็นปุ่ม **ลบใบสมัคร** แต่ละรายการ และ **จัดการข้อมูลทดสอบ / รีเซต**
- **ระดับ 1:** ลบใบสมัคร 1 ใบ (รวมชื่อนักกีฬา โค้ช และข้อมูลรายละเอียดฟุตบอล) ไม่แตะใบสมัครโรงเรียนอื่น
- **ระดับ 2:** รีเซตทุกรายชื่อและผลทดสอบของกีฬา/รุ่นที่เลือก
- **ระดับ 3:** รีเซตการลงทะเบียนและผลทดสอบทุกกีฬาของการแข่งขันปี 2569
- คง `sports_competitions`, `sports_schools`, `sports_events`, `sports_user_roles`, บัญชีโรงเรียน, รายการกีฬา, การแบ่งสาย, fixture, สถานที่/วันเวลาการแข่งขัน และผู้ดูแล E-Sport
- รีเซตคะแนนฟุตบอล/RoV/ทั่วไปและประวัติแก้ไขคะแนน (หลังเก็บสำเนา), ล้างคะแนนเหรียญและผลกีฬาเดี่ยว, ล้างผลที่กรรมการส่งเพื่อออกเกียรติบัตรหากยังไม่เคยออกเกียรติบัตรจริง
- สถานะคู่ฟุตบอลที่เคย `completed` กลับ `published` (หากมีวันเวลา) หรือ `draft`; คู่ RoV รอบแบ่งกลุ่มกลับ `scheduled` หากมีวันเวลา ส่วนรอบ Knockout กลับเป็นโครงเปล่า
- เก็บข้อมูลก่อนลบแบบ JSON ใน `sports_admin_reset_archives` พร้อมผู้ดำเนินการและเวลาที่ทำรายการ; **ยังไม่มีปุ่มกู้คืนอัตโนมัติ**

## ข้อป้องกันสำคัญ

1. **ต้องสำรองฐานข้อมูล Production และไฟล์จริงใน Storage ก่อนรีเซต** (Archive ใน DB ไม่มีเนื้อไฟล์ภาพ)
2. สามารถรีเซตได้ **ก่อนวันที่ 30 พฤศจิกายน 2569 เวลาไทย** เท่านั้น (หลังวันนั้นปิดฟังก์ชัน)
3. เฉพาะ Admin หลัก ไม่ใช่กรรมการฟุตบอล ไม่ใช่ delegated E-Sport Admin และไม่ใช่บัญชีโรงเรียน
4. คำสั่งตรวจสอบ (`preview`) ไม่ลบข้อมูลใด ๆ; คืนจำนวนใบสมัคร นักกีฬา ผล และภาพ พร้อม fingerprint
5. ต้องพิมพ์ **`ลบข้อมูลทดสอบ 2569`** ให้ตรงทุกตัวอักษร และยืนยันซ้ำในกล่องข้อความ
6. ถ้าข้อมูลเปลี่ยนหลังตรวจสอบ จะปฏิเสธการรีเซตจนกว่าจะ Preview อีกครั้ง
7. **ห้ามลบใบสมัครเดี่ยว** ถ้ารายการกีฬานั้นมีการประกาศผล/เกียรติบัตรแล้ว ให้รีเซตระดับรายการหลังตรวจสอบ (เฉพาะช่วงก่อนแข่งขัน)
8. **ถ้ามีเกียรติบัตรถูกออกแล้ว** ไม่อนุญาตรีเซตระดับรายการ/การแข่งขัน เพื่อป้องกันเลขเอกสารและ QR ใช้ไม่ได้โดยไม่มีขั้นตอนเพิกถอน
9. ในขั้นตอนรีเซตตารางข้อมูล SQL จะ **ไม่ลบไฟล์ภาพจริงทันที**; ระบบแสดงรายชื่อไฟล์ค้างให้สำรอง แล้วกดยืนยันลบรูปผ่าน Supabase Storage API อีกครั้ง
10. คลัง Archive เก็บข้อมูลส่วนบุคคลของนักเรียน ต้องจำกัดการเข้าถึงไว้ที่ Admin และจัดการตามนโยบายคุ้มครองข้อมูลส่วนบุคคล

## ติดตั้ง

1. ทำสำเนาโปรเจกต์และสำรอง Supabase (Database + Storage) ก่อน
2. รัน `supabase/migrations/202611230028_sports_safe_admin_reset.sql` ใน **Supabase SQL Editor** หลัง Migration `202611230027_sports_certificates_v1.sql` และ `202611230026_sports_football_four_categories.sql`
   - การติดตั้งไฟล์ SQL **ไม่ทำการลบข้อมูลใด ๆ**
3. วางไฟล์ TSX จาก ZIP ลงในโปรเจกต์ v33.3 เดิม (หากดาวน์โหลด ZIP แบบเต็ม ให้นำเข้าโปรเจกต์เดิมอย่างระมัดระวัง)
4. เปิด VS Code รัน `npm run build` และตรวจสอบให้ผ่าน จากนั้น Commit + Push เพื่อให้ Vercel Deploy
5. เข้าด้วยบัญชี Admin หลัก → **ลงทะเบียน** → **จัดการข้อมูลทดสอบ / รีเซต** หรือเปิด `/group-sports/reset`
6. เริ่มจาก **ลบใบสมัครทดลองรายการเดียว** ทดลองดูจำนวนใน Preview แล้วพิมพ์ข้อความยืนยัน
7. ทดสอบหน้าลงทะเบียนอีกครั้งว่าลบเฉพาะใบสมัครนั้น; รูปทดสอบยังอยู่ใน Storage รอให้สำรองและกดลบรูปอีกครั้ง
8. ทดสอบรีเซตผลฟุตบอลและ RoV ในฐานข้อมูล Staging ก่อน แล้วจึงเปิดใช้งาน Production

## ขอบเขตและข้อจำกัด

- เน้นข้อมูลทะเบียนนักกีฬาและผลการแข่งขันของกีฬากลุ่มปี 2569 **ไม่ลบเอกสารข้อมูลโรงเรียน พิธีเปิด ข้อมูลขบวนพาเหรด หรือผู้ใช้งาน**
- การจัดการข้อมูล E-Sport เดิมมีรีเซตผลเฉพาะ RoV อยู่แล้ว; v33.4 ครอบคลุมทั้งกีฬาพร้อมทะเบียนนักกีฬา แต่ต้องตรวจข้อมูลจริงก่อนสั่งลบ
- ถ้าติดตั้ง Migration ก่อนหน้าของฟุตบอล/เกียรติบัตรไม่ครบ จะต้องติดตั้งให้ครบก่อน
- เนื่องจากระบบไม่ได้เชื่อมต่อฐานข้อมูล Production ในการสร้าง Patch นี้ ยังไม่ได้ยืนยันว่า DB Schema Production มีส่วนขยาย/Foreign Key อื่นที่บล็อกการลบหรือไม่ เมื่อพบ FK เพิ่มเติมต้องปรับก่อนทดลองจริง
- `npm run build` / การเชื่อมต่อ Supabase จริง **ยังไม่ผ่านการทดสอบในสภาพแวดล้อมนี้**; กรุณาทดสอบบนเครื่องและส่ง Error ถ้ามี

**ไม่ต้องรันคำสั่ง `TRUNCATE`, ลบตาราง, ลบบัญชีโรงเรียน หรือรัน SQL รีเซตด้วยตนเองนอกฟอร์ม Admin นี้**
