# ระบบกีฬากลุ่ม v26.2 — เมนูย่อยแนวตั้งแบบขยายพื้นที่ (Soft Flow Dropdown)

ปรับจาก **v26.1** โดยแก้เฉพาะ `src/components/group-sports/GroupSportsDashboard.tsx` ไม่มีการเปลี่ยนฐานข้อมูลหรือ API

## การปรับปรุง

- **ข้อมูลสำหรับโรงเรียน**: เมนูย่อย 6 หัวข้อแนวตั้งบนพื้นขาว–ชมพูอ่อน (แทนพื้นแดงทึบ)
- **จัดการแข่งขัน**: เมนูย่อย 3 หัวข้อแนวตั้งในสไตล์เดียวกัน (แทนปุ่มแนวนอน 3 คอลัมน์)
- **เมนูไม่ลอยทับหน้าจอ**: ใช้ CSS grid expand/collapse ใน flow ของ `<nav>` ทำให้เนื้อหาด้านล่างถูกดันลงจริง
- **การเคลื่อนไหว**: 420 ms, ease-out, เลื่อนลงและ blur 3px→0 พร้อมเงาสีชมพูฟุ้งอ่อน ๆ รอบแผง; รองรับ `prefers-reduced-motion`
- **รายการที่เลือก**: พื้นชมพูอ่อน ตัวอักษรแดงเข้ม พร้อมไฮไลต์ปุ่มหลักสีแดงเข้มและเส้นสีทอง
- **ใช้งานมือถือ**: กล่องเมนูย่อยไม่เกิน 360px และคำนวณตำแหน่งให้อยู่ภายในขอบแถบเมนู
- **การใช้งานเดิม**: เปิด/ปิดโดยกดปุ่มหลัก ปิดเมื่อเลือกรายการ คลิกพื้นที่นอกเมนู หรือกด Escape

## การติดตั้งจาก Patch

1. ใช้กับโครงการ **v26.1** (หรือโครงการฉบับเต็ม v26.2)
2. แตก `student-activity-sports-soft-dropdown-v26.2-patch.zip`
3. คัดลอก `src/components/group-sports/GroupSportsDashboard.tsx` ไปทับตำแหน่งเดียวกันของโครงการ
4. Commit และ Push ผ่าน GitHub Desktop
5. ทดสอบบน Vercel Preview ให้ build ผ่าน จากนั้นจึงใช้ใน Production

## ตรวจสอบหลังติดตั้ง

- กดเมนู “ข้อมูลสำหรับโรงเรียน”: แผง 6 รายการสีอ่อนควรเลื่อนลงและ **ดันหน้าที่กำลังแสดงลง**
- กดเมนู “จัดการแข่งขัน”: แผง 3 รายการควรมีสไตล์เดียวกัน
- เลือก “รายการแข่งขัน”, “โปรแกรม / ผล”, “ลำดับขบวน”, “ส่งข้อมูลโรงเรียน”: หน้าเนื้อหาต้องเปลี่ยนถูกต้อง และเมนูยุบกลับ
- กด Escape / คลิกนอกเมนู: แผงยุบลงอย่างนุ่มนวล
- ทดลองจอเล็กและระบบตั้งค่า Reduce Motion
- ตรวจว่าเมนูเดิม “โรงเรียน”, “ลงทะเบียน”, “ตารางคะแนน”, “เหรียญรางวัล”, “บัญชีโรงเรียน” ยังใช้งานได้

## หมายเหตุ

ไม่มี SQL Migration และไม่ต้องเพิ่ม Environment Variables
แพตช์นี้ปรับเฉพาะการนำทางและการแสดงผล ไม่เปลี่ยนข้อมูลการแข่งขันหรือใบสมัคร

ตรวจไวยากรณ์ TypeScript/TSX ผ่าน แต่ **ยังไม่ได้รัน Next.js Production Build หรือทดสอบ Supabase จริงในสภาพแวดล้อมนี้**
