ติดตั้ง
1. สำรองโปรเจกต์/ฐานข้อมูลก่อน หยุด npm run dev ด้วย Ctrl+C
2. คัดลอกโฟลเดอร์จาก ZIP ไปยังโฟลเดอร์โปรเจกต์ที่มี package.json (merge ไม่ลบของเดิม)
   ตรวจ diff ไฟล์ร่วม 5 ไฟล์ก่อน Replace หากมีการแก้เองหลัง v33.28
3. รัน supabase/migrations/202611240045_sports_tabletennis_v33_29.sql ทั้งไฟล์ หลังยืนยัน 044 สำเร็จ
   SQL ใช้ transaction; หยุดถ้าโรงเรียนจับคู่ไม่ได้ รายการไม่ครบ หรือมีข้อมูลคู่แข่งขัน/โปรแกรมที่เผยแพร่เดิม
   ไม่สร้างโรงเรียนเพิ่ม ไม่ลบโปรแกรมเก่า และไม่เปิดเผยแพร่โดยอัตโนมัติ
4. รัน diagnostics/202611240045_check_tabletennis.sql คาดหวัง 15 แถว 75 คู่ ฉบับร่างทั้งหมด
5. npm run build; ผ่านแล้ว npm run dev; http://localhost:3000/group-sports/table-tennis
6. เข้าด้วยผู้ดูแลเพื่อตรวจต้นฉบับ วัน/เวลา/โต๊ะ จำนวนเกม และสถานที่ของแต่ละคู่
   ใช้เปิดรับสมัครกลาง ตรวจรายชื่อ ปิดรับสมัคร แล้วเผยแพร่ หลังผู้จัดยืนยันข้อมูล
