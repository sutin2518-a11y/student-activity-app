# ฟุตบอล v32.2 — แบบฟอร์ม A4 ทั้ง 4 หน้า + รูปเจ้าหน้าที่ทีม

ปรับจากโปรเจกต์ต้นฉบับ `ระบบกิจกรรม(1).zip` วันที่ 23 พฤศจิกายน 2569 โดยไม่เปลี่ยนตารางโปรแกรม 51 คู่ ไม่ลบข้อมูลนักกีฬาหรือแก้สิทธิ์ RoV

## สิ่งที่เปลี่ยน

1. เมนู **ลงทะเบียนนักกีฬา**: มีชื่อและเบอร์โทรศัพท์ **ผู้จัดการทีม** แยกจากชื่อผู้อำนวยการโรงเรียน (ชื่อไม่บังคับเพราะใบสมัครเก่าต้องยังเปิดได้) และยังเพิ่ม/ลบครูผู้ควบคุมทีมได้หลายคน (ไม่เกิน 30 คน) ครูคนแรกเป็นผู้ฝึกสอน คนถัดไปเป็นผู้ช่วยผู้ฝึกสอน
2. **แนบรูปเจ้าหน้าที่ทีม** หลังบันทึกใบสมัคร ในหน้ารายการเดียวกับรูปนักกีฬา: ผู้จัดการทีม ผู้ฝึกสอน ผู้ช่วยผู้ฝึกสอน รวมถึงเจ้าหน้าที่เพิ่มเติม
3. **ใบรายชื่อหน้า 1**: 20 คน + วันเกิด + หมายเลขเสื้อ + หมายเหตุ + ชื่อผู้จัดการทีมที่ระบุจริง
4. **ใบส่งรายชื่อหน้า 2**: แสดงผู้เล่นจริง/สำรองและ **อายุจำนวนปีเต็ม** ณ วันเริ่มแข่งขัน (รุ่น 15 ปี = 2 ธ.ค. 2569; รุ่นอื่น = 30 พ.ย. 2569) ไม่ใช่การตัดสินคุณสมบัติอัตโนมัติ; ฟุตบอลชายไม่จำกัดอายุคง 22 แถวตามเอกสาร แม้ลงทะเบียนได้ 20 คน
5. **แผงรูปหน้า 3**: 12 รูปนักกีฬา
6. **แผงรูปหน้า 4**: 8 รูปนักกีฬา + 4 รูปเจ้าหน้าที่ (ผู้จัดการทีม / ผู้ฝึกสอน / ผู้ช่วยผู้ฝึกสอน 2 คน) หากมีผู้ช่วยมากกว่าสองคน ระบบเพิ่มหน้าแผงรูปเจ้าหน้าที่เป็นเอกสารแนบ ไม่ตัดรายชื่อทิ้ง
7. ปรับขนาดตารางและรูปในไฟล์ CSS เพื่อให้พิมพ์ A4 แนวตั้งได้; ปุ่มพิมพ์รอโหลดภาพก่อน

### คอลัมน์ P/S/N สำหรับฟุตบอลชายไม่จำกัดอายุ

ในฟอร์ม v32.2 ระบบใช้: **P = ผู้เล่นจริง**, **S = สำรอง**, **N = ยังไม่ระบุสถานะ** และเพิ่มคอลัมน์อายุด้วย (ความหมายนี้เป็นนิยามในระบบสำหรับคอลัมน์ย่อ ไม่ใช่การยืนยันนิยามจากระเบียบต้นฉบับ) หากคณะกรรมการใช้ตัวอักษรเหล่านี้ต่างกัน ให้ยืนยันความหมายก่อนนำแบบพิมพ์ออกใช้จริง

## รูปเจ้าหน้าที่ — การจัดเก็บและการรักษาสิทธิ์

- ใช้ private bucket เดิมชื่อ `sports-athlete-photos` และ RLS จาก migration `202611220018_all_sports_private_athlete_photos.sql`
- ไม่มี URL สาธารณะ / ไม่มี bucket ใหม่ / **ไม่ต้องรัน SQL เพิ่ม** หาก migration เดิมลงครบแล้ว
- เก็บชื่อผู้จัดการทีมเป็น `manager_name`, `manager_phone` ใน JSONB ของ **ครูคนแรก** ที่ตาราง `sports_roster_staff.coaches` (ทำงานกับ RPC ฟุตบอล 0026 เดิม และใบสมัครเก่าที่ไม่มีฟิลด์นี้)
- รูปนักกีฬาใช้ index 0–19; รูปผู้จัดการทีม index 100; รูปผู้ฝึกสอนและผู้ช่วยใช้ 110+ ตามลำดับ จึงไม่ทับกัน
- ชื่อ/บทบาทเจ้าหน้าที่ถูกแปลงเป็นแฮชในชื่อไฟล์ ไม่มีชื่อและเบอร์โทรศัพท์ปรากฏเป็น path; หากแก้ชื่อหรือสลับลำดับ ต้องแนบรูปใหม่เพื่อไม่ใช้รูปของคนอื่นผิดตัว
- เจ้าของโรงเรียนและผู้ดูแลการแข่งขันที่มีสิทธิ์เท่านั้นที่อ่าน/แนบรูปได้ โดยอาศัย RLS เดิม

## วิธีติดตั้ง (แนะนำใช้ ZIP เฉพาะไฟล์แก้ไข)

1. สำรองโปรเจกต์ปัจจุบันและ Commit ไว้ใน GitHub Desktop
2. แตกไฟล์ `football-v32-2-changed-files.zip` แล้ว **คัดลอกเนื้อหาข้างในลง root ของโปรเจกต์เดิม** โดยคงโฟลเดอร์ `src/`, `tests/` และไฟล์ README ตามตำแหน่งเดิม (อย่าให้เกิดโฟลเดอร์ซ้อน)
3. ตรวจว่ามี migration 0026 ฟุตบอล และ 0018 รูปนักกีฬาทุกชนิดกีฬาใน Supabase แล้ว โดย **ไม่ต้องรัน SQL ใหม่**
4. ที่ root โครงการ: `npm ci` จากนั้น `npm run build` และ `npm run dev`
5. ล็อกอินบัญชีผู้ดูแลโรงเรียน → ฟุตบอล → ลงทะเบียนนักกีฬา → เปิดใบสมัครที่บันทึก → ระบุผู้จัดการทีม กดบันทึก → แนบรูปเจ้าหน้าที่และรูปนักกีฬา → พิมพ์ PDF (ตรวจ 4 หน้า)
6. หากแก้ไขแล้วถูกต้อง ให้ Commit / Push ด้วย GitHub Desktop และตรวจ Deploy ที่ Vercel

## การทดสอบที่ทำในชุดแก้ไขนี้

- `python verify_v32.py`: ผ่าน (51 คู่, 4 รุ่น, เอกสารเดิม, RPC เดิม)
- `node --experimental-strip-types --test tests/football-v32-2.test.mjs`: 4 tests ผ่าน
- ตรวจ syntax TS/TSX ที่เปลี่ยนด้วย TypeScript transpiler: ไม่พบ syntax error
- จำลองหน้าพิมพ์ใน Chromium แล้วตรวจตาราง 22 แถวและรูปหน้า 3–4: อยู่ในขนาด A4
- **ยังไม่ได้รัน `npm run build` ในระบบนี้** เนื่องจาก npm offline ไม่สามารถดาวน์โหลด dependency ที่ขาดได้ (ENOTCACHED)
- **ยังไม่ได้อัปโหลดรูปเข้าสู่ Supabase จริง หรือเปลี่ยนข้อมูล production** ต้องทดสอบด้วยบัญชีโรงเรียนหลัง Deploy
