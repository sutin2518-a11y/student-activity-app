# v30.1 — แบนเนอร์เฉพาะหน้า E-Sport (RoV)

ต่อยอดจากโครงการ v30 โดยแทนที่แบนเนอร์ข้อความเดิมบนหน้า `/group-sports/esports` ด้วยภาพ E-Sport RoV ภูลังกาเกมส์ 2569 ที่ผู้ใช้อนุมัติ

## สิ่งที่เปลี่ยน

- หน้า `/group-sports/esports` ใช้ภาพแบนเนอร์ใหม่ในไฟล์ `public/images/esports-rov-banner-2569.webp`
- คอมพิวเตอร์ (lg ขึ้นไป) แสดงภาพเต็มสัดส่วน 3:1 ไม่ตัดหัวข้อหรือข้อความที่อยู่ในภาพ
- มือถือและแท็บเล็ตแสดงภาพเป็นพื้นหลัง พร้อมข้อความจริงเพื่อให้อ่านง่ายเมื่อจอแคบ
- ปุ่ม «กลับหน้าผลการแข่งขัน», «โปรแกรมกีฬาทั้งหมด» และสถานะบัญชียังคงอยู่ในแถบบนของหน้า
- ไม่แก้ไขรายการแข่ง ผลการแข่งขัน การจัดกลุ่ม หรือสิทธิ์กรรมการ
- ใช้ภาพ WebP ความละเอียด 2172 × 724 ลดขนาดไฟล์ลงมากจาก PNG ต้นฉบับ

## ติดตั้ง

สำหรับผู้ใช้ที่มีโครงการ **v30** แล้ว:

1. สำรองโครงการเดิม
2. แตกไฟล์ `student-activity-esport-banner-v30.1-patch.zip` แล้วนำโครงสร้าง `src/` และ `public/` ไปทับในโครงการเดิม
3. Commit และ Push ผ่าน GitHub Desktop
4. ตรวจ Vercel Preview ที่ URL `/group-sports/esports` บนจอคอมพิวเตอร์และมือถือ
5. ตรวจว่าหน้ารายการผล E-Sport และปุ่มกลับหน้าผลการแข่งขันยังทำงานตามเดิม

หากยังไม่ติดตั้ง v30 สามารถใช้โครงการฉบับเต็ม `student-activity-system-updated-v30.1.zip` ซึ่งมีไฟล์ต่อจาก v30 รวมอยู่แล้ว

**ไม่ต้องรัน SQL เพิ่ม และไม่ต้องตั้งค่า Environment Variables เพิ่ม**

## การตรวจสอบ

- ใช้ TypeScript parser ตรวจไวยากรณ์ TypeScript/TSX 74 ไฟล์ ไม่พบ parse diagnostics
- ตรวจขนาดภาพ WebP เป็น 2172 × 724 (3:1)
- ตรวจไฟล์ ZIP ด้วยการทดสอบ CRC
- ยังไม่ได้ทดสอบ `next build` จริง เพราะแพ็กเกจ npm ที่จำเป็นไม่อยู่ใน offline cache
- ยังไม่ได้ Deploy หรือทดสอบเว็บไซต์ Production ของผู้ใช้
