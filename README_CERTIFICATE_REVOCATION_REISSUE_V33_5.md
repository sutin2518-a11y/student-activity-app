# ระบบยกเลิกและออกเกียรติบัตรฉบับใหม่แทน v33.5

## ความสามารถ
- ผู้ดูแลการแข่งขัน (Admin หลัก) เปิดแท็บ **จัดการเกียรติบัตร** ในหน้า `/group-sports/certificates/manage`
- ค้นหาเอกสารตามชื่อผู้รับ โรงเรียน หรือเลขที่เกียรติบัตร
- ยกเลิกเกียรติบัตรเป็นรายฉบับ โดยต้องระบุเหตุผลและยืนยันก่อนดำเนินการ
- เก็บแถวต้นฉบับ เลขที่เดิม และ QR token เดิมไว้ในฐานข้อมูล พร้อมบันทึกผู้ยกเลิก เวลา และเหตุผล
- ออกฉบับใหม่แทนเกียรติบัตรที่ยกเลิกแล้ว โดยใช้เลขที่ใหม่และ QR token ใหม่ เชื่อม `replaces_id` / `replaced_by` กับฉบับเดิม
- QR ของฉบับเดิมแสดงสถานะ **ถูกยกเลิกแล้ว** พร้อมเลขที่ฉบับใหม่ (ถ้ามี)
- QR ของฉบับใหม่ตรวจสอบเป็นเอกสารที่ใช้งานได้ และแสดงว่าออกแทนเลขที่เดิม
- การเปิด/ปิดเกียรติบัตรเข้าร่วมไม่สามารถเปิดใช้งานเกียรติบัตรที่ถูกยกเลิกโดยชัดแจ้งได้
- โรงเรียนยังเห็นเฉพาะเกียรติบัตรที่ active ของโรงเรียนตนเองผ่าน RPC เดิม

## ติดตั้ง
1. สำรองฐานข้อมูลก่อนติดตั้งตามขั้นตอนปกติของโครงการ
2. รัน `supabase/migrations/202611230029_sports_certificate_revocation_reissue.sql` ใน Supabase SQL Editor หลัง migration เกียรติบัตร v1 และ migration ก่อนหน้า
3. วางไฟล์แอปที่อยู่ใน ZIP ชุดแก้ไขทับโปรเจกต์ v33.4
4. รัน `npm run build` แล้ว Commit / Push เพื่อ Deploy

## วิธีใช้งาน
1. เข้าด้วยบัญชี Admin หลัก
2. เปิด `/group-sports/certificates/manage`
3. เลือกรายการแข่งขัน แล้วเลือกแท็บ **จัดการเกียรติบัตร**
4. กด **ยกเลิกเกียรติบัตร** ระบุเหตุผล และยืนยัน
5. หากต้องออกฉบับใหม่ ให้กด **ออกฉบับใหม่แทน** บนรายการที่ยกเลิกแล้ว ระบุเหตุผลและยืนยัน
6. โรงเรียนพิมพ์ฉบับใหม่ได้จากหน้าเดิม `/group-sports/certificates` หลังโหลดข้อมูลใหม่

## ข้อควรทราบ
- Migration นี้เป็นแบบ additive: เพิ่มคอลัมน์และ RPC ใหม่ ไม่ลบหรือแก้ผลการแข่งขัน/ใบสมัครเดิม
- การยกเลิกไม่ลบเอกสารเดิม เพื่อให้ตรวจสอบย้อนหลังได้
- การออกฉบับใหม่ทำสำเนาข้อมูลผู้รับ รายการ รางวัล และผู้ลงนามจาก snapshot เดิม แต่ได้เลขที่และ QR ใหม่
- QR เดิมจะไม่แสดงว่า valid อีกต่อไป
- ปุ่มจัดการอยู่ในหน้า Admin และ RPC ตรวจ `sports_stage3_admin` ฝั่งฐานข้อมูลด้วย ไม่อาศัยการซ่อนปุ่มบนหน้าเว็บเพียงอย่างเดียว
- ต้องทดสอบ migration กับ Supabase ของโครงการก่อนใช้งานจริง; การสร้าง ZIP ไม่ได้เปลี่ยนฐานข้อมูลออนไลน์โดยอัตโนมัติ
